# 统信 UOS 系统安装指南

## 环境要求

- 统信 UOS 桌面操作系统，支持 x86\_64（amd64）与 ARM64 架构。
- 具体支持的系统版本以当前版本说明为准。

TIP

不满足上述要求的系统将无法启动 WorkBuddy。

## 安装

统信 UOS 请通过系统**应用商店**下载安装 WorkBuddy。

1. 打开系统自带的**应用商店**，在顶部搜索框中输入 `WorkBuddy` 并搜索，进入 WorkBuddy 详情页，点击**安装**。

![应用商店搜索 WorkBuddy](https://download.codebuddy.cn/web/docs/1fd9c48bbf93dc8e5bc5a2622d78cebdfa6a21d4/docs/static/uos-store-search.DRCrRZ2J.png)
2. 等待安装完成，按钮变为**打开**后，点击**打开**即可启动 WorkBuddy。

![应用商店安装完成](https://download.codebuddy.cn/web/docs/1fd9c48bbf93dc8e5bc5a2622d78cebdfa6a21d4/docs/static/uos-store-open.Dxa9510H.png)

## 登录

1. 启动 WorkBuddy，点击**登录**按钮。

![WorkBuddy 登录界面](https://download.codebuddy.cn/web/docs/1fd9c48bbf93dc8e5bc5a2622d78cebdfa6a21d4/docs/static/uos-login-screen.vuOAZ2rk.png)
2. 浏览器自动打开登录页面（WorkBuddy 官网 **workbuddy.cn**），在当前页面的登录弹窗中勾选《用户服务协议》与《隐私政策》，使用**微信扫码**完成登录；也支持**手机号、邮箱、SSO** 等登录方式，登录全程在当前页面完成，无需跳转。

![微信扫码登录](https://download.codebuddy.cn/web/docs/1fd9c48bbf93dc8e5bc5a2622d78cebdfa6a21d4/docs/static/login-wechat-qr.Ci-o675k.png)
3. 页面显示登录成功后，返回客户端即可开始使用。首次使用可参考[开启你的第一个任务](https://www.workbuddy.cn/docs/workbuddy/FirstTask)。

语言设置

	- 如需切换界面语言，点击左下角**头像** \> **设置** \> **通用** \> **语言**，进行切换。
	- 如果点击登录后无法打开浏览器、登录失败或客户端无响应，可参见 [常见问题](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/FAQ)。

## 版本更新

点击左下角**头像** \> **检查更新**，系统将自动检测版本。若已是最新版本则无需操作；若存在新版本，将引导你前往**应用商店**完成更新。
