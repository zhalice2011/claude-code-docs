# 默认权限与安全沙箱

WorkBuddy 可以帮你读写文件、整理目录、生成文档，也可以在需要时调用脚本或外部程序。为了兼顾效率和安全，WorkBuddy 提供**默认权限**和**完全访问权限**两种权限模式。日常建议使用默认权限：让 AI 在工作空间内高效执行任务，但遇到高风险操作时先停下来向你确认。

你可以把它理解成一层安全护栏：日常处理任务时不挡路，真正要越过边界或执行危险动作时，会要求你再看一眼、点一次确认。

## 权限模式

### 在哪里切换权限模式

权限入口位于输入框底部，为常驻的权限状态按钮，默认显示为「默认权限」。点击按钮可查看当前权限状态及说明，并通过「允许完全访问」开关在**默认权限**和**允许完全访问**之间切换。 权限状态在输入框上始终可见，你在发起任务前可以随时确认当前处于哪一档。日常建议保持默认权限；只有在可恢复、可隔离的任务里，才短时间切到完全访问权限。

![权限切换入口与状态面板](https://download.codebuddy.cn/web/docs/3754a028cd26c05d858852b7fbcedeb54159906e/docs/static/permission-menu.D2eTfMb0.png)### 默认权限

#### 默认权限会保护什么

在默认权限下，WorkBuddy 重点保护的是重要资产和高风险动作。开启删除保护后，普通文件写入通常可以直接继续。但一旦涉及敏感路径、重要删除、脚本命令或网络等风险操作，WorkBuddy 仍会停下来让你确认。通常需要确认：

| 操作类型 | 说明 |
| --- | --- |
| 写入受保护或敏感路径 | 避免覆盖密钥、凭据或安全配置 |
| 删除受保护文件、重要目录或批量删除 | 避免误删难以恢复的资料；普通单文件删除通常由删除保护兜底 |
| 执行脚本、命令或外部程序 | 可能修改文件、访问网络或影响系统环境 |
| 网络访问或敏感能力 | 命中安全中心规则或高风险能力时会要求确认 |

如果你取消确认，WorkBuddy 不会执行这一步。你可以继续和 WorkBuddy 对话，让它换一种更安全的处理方式，例如先列出将要删除的文件清单，或把结果保存到工作空间内。 沙箱还会额外提供几层保护：

- 命令会优先在沙箱约束下执行；如果被拦截，再按风险决定是否需要你确认。
- 删除保护会尽量通过安全删除或回收站降低误删风险。
- 文件备份会在修改已有文件前保存备份，新建文件不重复备份，可在**设置 \> 安全中心**开启或关闭。

#### 权限生效范围

默认权限以**工作空间**为边界，工作空间内的常规文件操作通常可以直接执行；当操作超出工作空间范围或涉及需要确认的高风险操作时，WorkBuddy 会暂停当前操作并请求确认。

**工作空间**是当前任务主要读取和保存文件的文件夹。在新建任务时选择的目录，或 WorkBuddy 自动创建的任务目录，都会作为本次任务的工作空间。

建议把本次任务需要处理的文件放进同一个工作空间，例如：

- `周报整理`
- `发票归档`
- `客户资料清洗`
- `图片批量处理`

这样 WorkBuddy 可以更顺畅地处理文件，也能让默认权限更准确地判断哪些操作属于本次任务范围。

建议

处理重要资料前，优先为任务新建一个独立文件夹，只把需要处理的副本放进去。默认权限可以减少误操作风险，但不能替代备份。

#### 为什么默认权限更稳

脚本分析通常是先看一段命令或脚本内容，判断它看起来是否危险。但实际执行时，风险可能来自很多地方：

- 脚本内部又调用了其它脚本或工具；
- 文件路径由运行时动态生成，开始时不容易完全看出来；
- 一个普通命令可能因为参数不同而删除、覆盖或移动大量文件；
- 外部程序的真实行为不一定能只靠脚本文本判断。

默认权限的保护点不只停留在“看起来像什么”，而是在 WorkBuddy 准备进行高风险操作时，再要求用户确认一次。也就是说，即使普通文件写入可以更顺畅地继续，只要下一步触发上面的确认条件，WorkBuddy 仍会把决定权交还给你。

这让默认权限更适合日常办公：AI 可以继续自动完成大部分低风险步骤，你也能在关键节点拦住可能造成损失的动作。

### 完全访问权限

开启**允许完全访问**后，WorkBuddy 会关闭上述二次确认。执行高风险操作时不会再逐步请求确认，包括写入文件、删除文件、执行脚本和调用外部程序。

**生效范围：当前客户端内所有任务。** 开启完全访问权限后，当前客户端内**所有已存在任务和后续新建任务**统一生效；在对话过程中关闭后，所有任务恢复默认确认流程。该设置**不跨设备生效**，每台客户端独立管理。

这会显著减少确认弹窗，但也意味着：如果任务理解错了目录、脚本写错了路径，或外部工具行为不符合预期，操作可能直接影响你的电脑文件。

当你从下拉菜单切换到完全访问权限时，会看到「确认允许完全访问？」弹窗，其中明确列出将放开的能力（**文件操作、终端命令、访问互联网**），并提示所有任务将减少确认步骤、直接操作你的电脑。请先确认当前任务和文件都可恢复，再勾选风险确认并点击「允许完全访问」；不确定时直接取消，继续使用默认权限。

![完全放开确认弹窗](https://download.codebuddy.cn/web/docs/3754a028cd26c05d858852b7fbcedeb54159906e/docs/static/full-access-confirm.DJ7-S_dk.png)请谨慎开启

允许完全访问不等于更安全，也不会自动帮你判断所有风险。它只是把确认环节交给 AI 自动通过。建议只在完全可信的任务、隔离环境或临时测试目录中使用，例如 Docker、虚拟机、一次性工作目录。

不建议在以下场景开启允许完全访问：

- 正在处理生产资料、客户资料、财务资料或唯一副本；
- 工作目录靠近桌面、下载目录、个人文档根目录或项目仓库根目录；
- 任务会批量删除、批量重命名或覆盖文件；
- 任务需要运行你不了解的脚本或第三方工具；
- 当前电脑里有重要文件，且没有备份。

### 如何选择权限模式

两种权限模式的适用范围和风险不同，可以根据任务的操作范围和运行环境，选择合适的权限模式。

| 对比项 | 默认权限 | 完全访问权限 |
| --- | --- | --- |
| 文件访问范围 | 沙箱约束内，越界需请求允许 | 计算机上任意位置 |
| 删除 / 修改文件 | 需逐次确认 | 多数直接执行 |
| 终端命令 | 系统级命令需确认 | 可直接运行命令、安装软件、改系统设置 |
| 访问互联网 | 受控，敏感动作需确认 | 可访问网站、发送数据、使用已启用连接器 |
| 打断频率 | 较高 | 很低 |
| 生效范围 | 当前任务 | 全局，所有任务统一生效 |
| 风险等级 | 低 | 高 |
| 适用场景 | · 日常文档生成· 表格处理· 资料整理· 第一次处理某类任务· 目标不明确时优先使用 | · 隔离目录中反复运行可信脚本· Docker、虚拟机或临时测试环境中的实验 |

建议

- 默认权限下，批量删除、移动或覆盖文件时，确认前仔细检查路径和文件清单。
- 完全访问权限下，仅建议短时间开启，生产环境、重要设备、唯一文件副本等场景不建议开启。
### 权限确认与处理

在默认权限下，当 WorkBuddy 执行涉及文件修改、删除或命令运行等受控操作时，可能会暂停当前操作并请求确认。收到确认提示后，建议先检查以下信息：

1. **操作内容**：是写文件、删文件，还是执行脚本。
2. **影响范围**：目标路径是否在本次任务的工作空间内，是否会影响桌面、下载目录、项目源码或其它重要目录。
3. **执行理由**：这一步是否确实是完成任务所必需的。

如果无法确认当前操作是否合适，可以先取消本次操作，让 WorkBuddy 先：

- 展示将要修改或删除的文件清单。
- 生成预览或备份。
- 将输出保存到工作空间内。
- 解释脚本内容和执行原因后再运行。

### 权限使用建议

为降低误操作对文件和系统环境的影响，建议根据任务风险选择合适的权限模式，并在执行重要操作前保留必要的检查环节。

1. **为任务准备独立工作空间**：尽量为每个任务使用独立文件夹，减少对其他文件的影响。
2. **重要文件提前备份**：执行批量处理、删除或重命名操作前，确认重要文件已有可恢复副本。
3. **默认使用默认权限**：让 WorkBuddy 在关键风险点向你确认。
4. **看懂确认弹窗再继续**：重点检查操作类型、路径和影响范围。
5. **不确定时先取消**：让 WorkBuddy 先解释、预览或生成清单，再决定是否继续。
6. **允许完全访问开关用完即关**：仅在任务可信、环境隔离且结果可恢复时短时间使用，完成后及时恢复默认权限。

默认权限不会干预大多数正常操作，而是在可能影响重要文件或系统状态的操作前增加确认。这样既可以保持任务的自动执行，又能在关键操作节点提供人工确认。

### 常见问题

**Q：默认权限会不会让模型什么都做不了？**

不会。沙箱内的常规操作照常执行，只有越界和高危操作才需要确认。日常写作、分析、生成文档等任务基本不受影响。

**Q：完全访问权限只对当前这个任务生效吗？**

不是。它是全局开关，开启后所有任务都会切到完全访问权限，包括之后新建的任务。

**Q：开启完全访问后还能关回去吗？**

可以。回到输入框底部的权限面板，关闭「允许完全访问」开关即可恢复默认权限。

**Q：默认权限下模型每一步都要问我吗？**

不是每一步，只有超出沙箱范围或属于高危类型（删除、修改、系统命令、对外发送等）的操作才会询问。

## 安全中心

安全中心用于统一管理 WorkBuddy 的安全、数据保护和运行环境相关配置。

权限模式决定任务执行时的整体访问范围；安全中心则可以进一步细化文件、命令、网络、数据和运行时等方面的安全策略。你可以根据使用场景调整相关配置，在保持任务执行能力的同时，对访问和操作范围进行更细粒度的控制。

### 功能概览

安全中心包含多项安全与运行时配置，各配置项按照功能分组进行管理。部分配置会进一步提供详细的设置项或保护机制，具体说明如下。

| 分组 | 配置项 | 说明 |
| --- | --- | --- |
| **沙箱安全** | 沙箱安全 | 总开关：AI 运行于隔离沙箱，并配置文件、命令、网络访问策略。保护您的数据，AI 对受保护文件的修改和删除操作需要授权。 |
| 文件安全 | 按文件路径配置三态规则，读取 / 写入 / 删除可分别设为允许、询问或拒绝。 |
| 命令安全 | 按命令前缀配置允许、询问或禁止规则。 |
| 网络安全 | 按域名 / URL 配置网络访问规则，并支持 HTTP 请求拦截。远程 HTTP 请求默认询问，本地 HTTP 请求默认放行，域名白名单内的访问不受影响。 |
| 自动备份 | 每轮对话修改文件之前自动备份，详见[自动备份。](#自动备份) |
| **工具管控** | Tool 管控 | 管理 Agent 可调用的产品工具和 MCP，支持按工具、MCP 服务及工具粒度启用或禁用，禁用后执行前拦截，配置对当前客户端内的所有 Agent 生效。详见[工具管控。](#工具管控) |
| **数据安全** | 安全网关 | 工作空间出入流量统一经过安全网关安全处理（默认开启）。 |
| 传输加密 | 本地与云端通信使用端到端加密通道（默认开启）。 |
| 敏感保护 | 默认开启。检测并拦截票据、密码等敏感信息的意外泄露，支持自定义检测规则，详见[敏感保护。](#敏感保护) |
| 删除保护 | 开启后优先移到废纸篓 / 回收站，关闭后按系统删除；遇回收站空间不足、文件超大、特殊删除指令等情况时，可能无法将文件移动到回收站。 |
| 批量删除审批 | 一次删除达到设定数量（默认 50）时需要审批；需先开启删除保护。 |
| **内置运行时** | 内置运行时 | 允许使用随包提供的运行时工具。 |
| **审计中心** | 审计中心 | 记录拦截 / 放行日志，支持导出日志与清空记录。 |
| **系统授权**（仅 macOS） | 完全磁盘访问权限 | 允许访问磁盘上的所有文件，部分功能需要此权限才能正常工作。 |
| 辅助功能 | 允许响应键盘快捷键，便于快捷唤起等功能。 |
| 自动化 | 允许给其他 App 发指令，比如帮你管理日历、提醒事项、备忘录等。 |

### 工具管控

在安全中心可以逐个启用或禁用 Agent 可调用的工具和 MCP 服务，减少不必要的联网、文件访问、命令执行或外部服务调用。 配置对当前客户端生效，当前客户端内的所有 Agent 共用这套工具管控策略。禁用某个工具后，Agent 在实际调用该工具前会被拦截。

- **工具页**：产品工具支持逐个启用或禁用。文件读写、命令执行等必要工具可进入**必要工具管理**页面行管理；关闭前会提示可能影响 Agent 完成通用任务。
- **MCP 页**：按 MCP 服务整体启停，支持逐工具控制的服务可展开单独配置，部分 MCP 仅支持整体关闭服务。提供**自定义 MCP** 统一开关，关闭后所有自行添加的 MCP 均不可调用。

配置保存在本地，对当前客户端内所有 Agent 统一生效，修改后对后续工具调用即时生效。

### 自动备份

在**沙箱安全**中开启**自动备份**后，Agent 修改已有文件前会自动生成一份快照；新建文件不重复备份。开启后，文件修改可直接进行，不再逐个弹窗询问。

- 同一个文件在一次对话轮次内，只在首次修改前生成快照
- 可点击**打开备份目录**查看当前会话的备份文件
- 所有会话共享备份空间，默认上限 3000 MB；空间不足时按时间顺序清理最早的备份

TIP

自动备份默认开启，建议保持。它不替代你自己的重要文件备份，仅用于在 Agent 改错时快速回退。

### 敏感保护

敏感保护**默认开启**，开启后使用敏感信息识别库自动识别并保护你的敏感信息（如密钥、凭证等）。点击**敏感保护**右侧的设置入口，可进入独立配置页，包含两个页签：

![敏感保护设置入口](https://download.codebuddy.cn/web/docs/3754a028cd26c05d858852b7fbcedeb54159906e/docs/static/permission-sensitive-entry.5ibYcD1-.png)

**自动检测规则**

- 内置**系统规则库**，覆盖常见凭证类型（如 1Password Secret Key、各类 API Key、Client Secret 等），每条规则可**单独开关**；
- 每条规则标注检测方式：**关键词检测**、**正则匹配检测**、**熵值检测**；支持加密的规则会标注「支持加密」标签；
- 支持按来源、状态筛选，及按名称 / 规则内容搜索；
- 点击**添加检测规则**可自定义规则，保存时会自动校验规则正确性。

![敏感保护自动检测规则](https://download.codebuddy.cn/web/docs/3754a028cd26c05d858852b7fbcedeb54159906e/docs/static/permission-sensitive.qr2AlxeJ.png)

**敏感数据管理**

- 命中提示时选择**允许并加密保护**的明文会保存在此处，并生成对应密文；
- 后续对话以密文参与上下文流转，在输出环节自动还原为明文，功能不受影响；密文不支持手动配置。

**检测范围与提示**

- **输入检测**：沙箱内打开较小的文件、读取文件内容、以及在输入框输入时进行检测；
- **输出检测**：执行命令、联网搜索或抓取网页等对外动作前进行检测；
- 命中后弹窗提示（如「是否允许模型访问敏感凭证？」，并展示凭证内容）：输入侧可选择**允许访问 / 允许加密访问（推荐）/ 禁止访问**，输出侧可选择**允许 / 禁止**；
- 部分内置能力（如通过 MCP Token 调用的工具）已在白名单内，不会弹出确认。
