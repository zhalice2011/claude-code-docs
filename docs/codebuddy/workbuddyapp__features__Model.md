## 三、查看模型配置

模型选择面板里，每个模型都会显示名称、能力标签和积分倍率，据此先选模型：

![模型选择面板：模型名称、能力标签与积分倍率](https://download.codebuddy.cn/web/docs/a2b1163fb126ec6f3bf00e80c52246a330059206/docs/static/model-config-entry.jCEaunlz.png)

选好模型后，点击面板右上角的配置入口，可以进一步调整这个模型的参数：

![模型配置页：上方显示当前模型，下方是可调整项](https://download.codebuddy.cn/web/docs/a2b1163fb126ec6f3bf00e80c52246a330059206/docs/static/model-config.uSqKCxzI.png)

页面上方显示**当前模型**，下方列出这个模型支持的配置：

| 配置 | 说明 |
| --- | --- |
| **思考强度** | 单选，档位随模型而定，例如 低 / 中 / 高 / 超高，当前档位显示在右侧 |
| **上下文窗口** | 单选，例如 300K / 1M；窗口越大，单轮对话消耗的积分越多 |

调整方式：

1. 点击要改的配置项，在弹出的选项列表里选一档；
2. 选好后返回配置页，右侧显示新的值，模型选择面板和输入框也会同步；
3. 保存失败会提示并提供重试，此时不要按尚未保存成功的配置开始任务。

说明

- 只打开配置页看看、不选任何选项就返回，当前配置不会变；
- 模型不支持的配置项不会出现在页面上，不会有点了没反应的入口；
- 从一个模型换到另一个模型时，会按新模型支持的档位重新校验，不会沿用上一个模型不支持的设置；
- 移动端不提供「配置自定义模型」的入口，模型列表里只列可用的模型。
## 四、能力标签

| 标签 | 含义 |
| --- | --- |
| **推理** | 支持逻辑推理、任务规划与多步骤执行 |
| **视觉** | 支持图片理解（拍照、截图场景请选择此类模型） |

## 五、积分消耗

不同模型的积分消耗有所不同。在模型选择面板中，每个模型名称下方会标注相应的积分倍率（如 x0\.80、x1\.00 等），数字越低消耗越少。

> **省钱小技巧**：日常简单任务选择性价比高的推理模型，需要图片理解时再切换到带「视觉」标签的模型。如果不确定选哪个，使用默认的 **Auto** 即可，系统会自动匹配最优模型。
