# 网站应用开发与发布

WorkBuddy 可以根据需求生成网站应用，按需接入云数据库、身份认证和文件存储等能力，并直接发布上线。无需自行购买服务器，也不用配置部署和日常运维。

## 选择网站应用还是轻量发布

[轻量发布](./../Library/Lightweight-Publish)和网站应用都可以快速发布为在线链接，可以根据内容的创建方式和后续使用需求进行选择。

| 你的需求 | 可以选择 |
| --- | --- |
| 把页面快速发布为在线链接 | 轻量发布、网站应用 |
| 使用 HTML 和 CSV 制作持续维护的看板、台账或工作台 | 轻量发布 |
| 让用户注册登录、提交信息或上传文件 | 网站应用 |
| 区分普通用户、管理员等不同角色 | 网站应用 |

网站应用包含云服务，需要保存用户数据、支持注册登录或管理不同角色时按需开启即可，无需另外接入服务。

## 生成网站应用

你可以通过以下三种方式创建：

1. 在 WorkBuddy 首页进入「代码开发」，选择「网站开发」或「Agent 应用」，使用推荐提示词开始创建；

![首页代码开发中选择 Agent 应用](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/webapp-create-scene.C4zk7VQm.png)

2. 直接用自然语言描述需求，并明确说明要制作网站应用。

描述需求时，建议说清楚谁来使用、需要完成什么操作，以及数据是否需要长期保存。例如：

```
制作一个课程预约网站应用。学员可以选择上课时间并填写姓名和手机号，提交后名额自动减少；老师可以查看每个时段的预约名单。预约记录需要保存到云端。完成后发布上线。
```
如果应用需要 AI 回答问题、生成文案或总结内容，在需求中说明“接入大模型”即可。WorkBuddy 会为应用接入 AI 能力，无需申请 API Key 和配置模型服务。例如：

```
制作一个智能客服网站应用。访客可以输入产品使用问题，应用通过大模型生成回答。完成后发布上线。
```
3. 如果已经生成 HTML 页面，也可以在原任务中继续提出需求，例如“为这个页面加入用户登录和数据保存”，将现有页面升级为网站应用。

## 预览和修改

生成完成后，对话中会出现网站应用卡片。点击卡片，可以在右侧预览区查看运行效果。

需要调整时，直接在对话中说明要修改的内容。例如：“把报名按钮移到页面顶部”“增加按日期筛选的功能”。

## 开启云服务

当应用需要保存数据、用户登录或上传文件时，WorkBuddy 会在生成过程中询问是否开启对应云服务。确认后 WorkBuddy 会继续完成相关配置，无需手动填写技术参数。具体的功能介绍和使用方式请参见[云服务](./Cloud-Services)。

| 对应能力 | 使用场景 |
| --- | --- |
| 云数据库 | 保存和管理用户提交的信息 |
| 身份认证 | 支持用户登录，并区分不同用户的数据或权限 |
| 文件存储 | 上传并保存图片或附件 |
| 数据统计 | 查看用户数量和注册趋势 |

你可以点击应用标题旁的「云服务」进行管理。

![点击应用标题旁的云服务](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/webapp-cloud-entry.BYkfGfvj.png)

## 发布网站应用

![点击预览区工具栏中的分享](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/webapp-publish-share.CYsjb0rG.png)

![网站应用分享面板](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/webapp-publish-panel.CigFdgNM.png)

应用制作完成后，点击预览区工具栏中的「分享」，也可以直接在对话中说「发布」、「上线」，即可获得独立的网站链接。发布后，任何获得链接的人都可以访问应用。

发布前，建议检查用户能否正常登录、提交的数据是否成功保存，以及不同角色看到的内容是否符合权限设置。同时确认页面及其中展示的数据适合对外公开，避免敏感信息随应用一同发布。

### 更新和下线应用

修改应用后，线上版本不会自动变化。重新打开分享面板点击「更新」，或者直接在对话中说“更新发布”，即可同步修改。更新后访问链接保持不变，已经分享出去的链接会直接打开新版本。

![已发布应用的分享面板，支持更新和下线](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/webapp-publish-update.Bjh1cc-s.png)

如果暂时不希望别人继续访问，可以在分享面板中点击「下线」，或者直接在对话中说“下线这个应用”。下线后，原链接将无法打开，但应用和云服务中的数据仍会保留。

## 管理已发布的应用

![在设置的数据管理中查看已发布的应用](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/webapp-manage-apps.Db7zSTYT.png)

进入「设置 \> 数据管理 \> 应用」，可以集中查看所有应用、查看发布链接，并管理云服务和发布状态。需要继续修改时，可以点击对应的任务名回到对话中提出修改要求。

如果只是暂时不想公开，请选择下线，应用和数据仍会保留。只有确定不再需要时再删除应用，删除后应用和云服务数据无法恢复，请提前导出需要保留的内容。
