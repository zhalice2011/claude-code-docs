# 轻量发布

轻量发布支持将本地 HTML 页面发布为在线链接，也可以结合 CSV 数据构建可持续更新的轻应用，方便分享作品或管理日常业务数据。

## 选择合适的发布方式

根据内容特点和使用需求，可以选择不同的方式：

| 使用目标 | 推荐方式 | 适用场景 |
| --- | --- | --- |
| 展示和分享内容，数据不需要频繁更新 | HTML | 汇报报告、项目复盘、旅游攻略、作品集 |
| 持续记录、查询和更新业务数据 | HTML \+ CSV | 项目管理看板、客户跟进、个人工作台、电商管理系统、记账 |

## 发布本地 HTML 页面

在 WorkBuddy 中打开本地 HTML 页面时，页面地址通常是本地文件路径（如 `file://`）或 `localhost` 地址，只能在当前电脑访问。 例如：

```
file:///tmp/lib_demo/2026中国AI办公协作市场分析报告
```
把这个地址复制给同事是打不开的——本地路径只指向你自己的电脑。 但将页面发布为网站后，可以生成在线链接，方便其他人通过浏览器访问。

TIP

发布前，可以先完善页面内容和样式。本地 HTML 产物支持可视化编辑，可以选中元素调整样式，也可以使用 AI 编辑修改，详见内容管理中的[本地 HTML 可视化编辑](./Content-Management#本地-html-可视化编辑)。

### 发布为网站

1. 在 WorkBuddy 中打开需要发布的 HTML 页面。
2. 点击页面右上角的**分享**图标，在弹窗中切换到**发布**页签，打开**发布为网站**开关，页面即被发布为在线链接，任何获得链接的人都可以访问。

![在分享弹窗的「发布」页签中开启「发布为网站」](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/publish-as-website.wn29MtFZ.png)

3. 开关下方会显示生成的链接，点击右侧按钮即可复制。
4. 弹窗底部还可以直接分享到微信等渠道，或生成二维码。发布后的链接使用 `workbuddy.link` 域名，形如 `https://workbuddy.link/p/{页面 ID}`。分享发布后的页面时，分享消息的封面为页面首页截图（分享会话的发布态除外）。

注意事项

- **发布为网站**开关默认关闭。开启后，获得链接的人可以访问页面；不再需要对外分享时，可以关闭该开关，停止通过发布链接访问页面。
- 发布操作不会改变页面内容，只是将访问方式从本地访问变为在线链接访问。同时，页面内容也会保存到资料库，后续可以在[内容管理](./Content-Management)中找到并继续编辑。
- **发布前请注意：** 确认页面及其引用的数据适合对外公开，不包含敏感信息，且页面内容符合相关法律法规和平台规则。发布者需对发布内容负责。
### 分享链接与协作

发布页面后，可以通过在线链接分享内容。如果需要邀请他人共同编辑，也可以在同一个分享弹窗中切换到右侧的**邀请协作**页签。

两个页签的用途不同：

- **发布为网站**：生成在线访问链接，供他人查看页面，属于只读访问。
- **邀请协作**：邀请他人参与页面编辑和协作。

## 使用 HTML \+ CSV 构建轻应用

HTML 与 CSV 配合使用，可以将页面展示与业务数据分开管理。HTML 负责页面展示和交互操作，CSV 负责存储业务数据，两者结合后，既能通过页面查看和修改数据，也能将更新同步到数据表中。

两者的分工如下：

| 层级 | 形态 | 主要职责 | 维护方式 |
| --- | --- | --- | --- |
| 展示与操作层 | HTML | 展示经营指标、业务待办，提供表单和交互操作 | 由 Agent 生成，需要调整布局或交互时继续对话修改 |
| 数据层 | CSV | 存储商品、订单、库存等结构化业务数据 | 由人或 Agent 持续维护，更新数据无需重新制作页面 |

这种方式有两个优势：

- **数据独立维护**：业务数据保存在 CSV 中，不写死在页面代码里。更新数据时只需维护 CSV，无需重新制作页面。
- **数据双向同步**：页面中的修改可以写回 CSV，CSV 更新后，页面也能读取最新数据。

后续需要增加字段、调整配色或增加筛选功能时，可以继续通过 WorkBuddy 任务对话进行修改。

### 准备 HTML 页面和 CSV 数据

开始搭建前，先明确页面需要展示和操作的内容，以及需要维护的数据。

例如，构建一个经营工作台时，可以使用 HTML 页面集中展示经营指标、业务待办和操作入口。

![用 HTML 搭建的经营工作台页面](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/app-html-dashboard.eeMbubAk.png)

再用目录和多张 CSV 表持续管理商品、订单与库存数据。

![用多张 CSV 表管理业务数据](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/app-csv-library.DXpZTSNj.png)

准备页面和数据时，建议先明确：

- **数据内容**：需要管理哪些数据，以及每项数据包含哪些字段。
- **页面展示**：需要展示哪些信息，例如数据列表、统计指标和详情。
- **交互操作**：是否需要通过页面新增、修改、查询或筛选数据。

### 将 CSV 数据接入 HTML 页面

准备好页面需求和 CSV 数据后，可以通过 WorkBuddy 任务对话，让 Agent 将 CSV 作为数据源接入 HTML 页面。

描述需求时，可以明确以下内容：

- **数据来源**：指定需要使用的 CSV 数据表。
- **展示方式**：说明需要展示哪些字段，以及页面布局。
- **交互操作**：说明是否需要新增、修改、查询或筛选数据。
- **数据同步**：要求页面与 CSV 数据保持同步，避免将业务数据直接写死在 HTML 中。

例如，可以提出这样的需求：

> 请基于现有商品 CSV 数据表，创建一个商品管理工作台。页面需要展示商品名称、分类、价格和库存，支持按分类筛选商品，并可以新增和修改商品信息。页面使用 CSV 作为数据源，确保在具备相应写入权限时，页面中的数据操作能够同步更新到数据表。

### 检查数据展示与同步

页面生成后，先预览轻应用，检查页面展示和数据操作是否正常。

重点确认：

1. 页面能否正确读取 CSV 中的数据。
2. 页面中的字段与 CSV 数据表是否对应。
3. 页面中的数据修改是否按预期同步到数据表。
4. 更新 CSV 数据后，页面能否读取最新数据。

需要注意，发布为网站提供的是只读访问，不代表获得发布链接的访问者可以修改 CSV 数据。若需要多人共同维护业务数据，应通过具有相应编辑权限的协作方式进行。

### 发布和分享轻应用

确认页面展示、数据同步和访问权限符合预期后，可以参考上方「发布为网站」的操作，将 HTML 页面发布为在线链接。

发布前，请再次确认页面及关联数据适合对外访问，避免将不适合公开的业务数据一同发布。

更多关于 MD、CSV 与 HTML 各自职责的说明，参见[多人多 Agent 协作](./Collaboration)。
