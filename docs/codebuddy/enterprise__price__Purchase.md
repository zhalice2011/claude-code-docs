## 常见问题

### Q：什么是企业版？

CodeBuddy \& WorkBuddy 企业版可满足个人、团队及企业在 AI 研发中的各类场景需求。企业版账号支持登录到各个产品形态上使用。

### Q：企业版有什么优势，个人是否可以使用？

企业版支持用量及研效管理，个人也可以使用企业版。

## 购买指南

### 购买入口

访问 **[购买企业版](https://copilot.tencent.com/pricing/)** 发起企业新购。

### 购买步骤

#### 第一步：填写购买信息

1. **选择许可证数量**：1 个坐席起购（企业旗舰版）
2. **设置超级管理员手机号**：手机号将作为发货依据，请谨慎填写
3. **选择企业**：
	- 企业版使用「腾讯统一身份」作为企业成员与组织管理平台
	- 可选择已创建过的腾讯统一身份企业
	- 若未创建过，购买后将自动创建
4. **选择购买时长**：可按月或按年订阅

> **建议**：购买时勾选「自动续费」，避免到期影响业务使用

![alt text](/docs/static/1.fRr303hf.png)

#### 第二步：确认订单

点击「立即购买」确认订单信息。

![alt text](/docs/static/2.4T5Usz6d.png)

#### 第三步：完成支付

支付方式：

- 腾讯云账户余额
- 在线支付

![alt text](/docs/static/3.wwKF-91D.png)

#### 第四步：进入管理后台

支付成功后：

1. 根据页面提示点击跳转至旗舰版管理后台
2. 或使用超管手机号登录 [管理后台](https://copilot.tencent.com/admin/)

![alt text](/docs/static/4.CIaitU50.png)

> **注意**：
> 
> - 后台需要 3\-5 分钟配置产品资源，若后台未刷新资源请耐心等待

![alt text](/docs/static/5.CVEBegnQ.png)

> - 若关联多个企业后台，需选择刚刚支付成功的账号进行登录

![alt text](/docs/static/6.B8h9EThl.png)

## 用量管理

### 查看剩余用量

#### 企业成员

用户可通过官网个人主页查看积分使用历史及当前用量。若用户为企业版企业成员，还可查看企业为其添加的额度信息。

1. 登录 [官网](https://www.codebuddy.cn/home/)。
2. 点击右上角头像，进入 个人主页/用量管理。

![alt text](/docs/static/image-5.Do31LegI.png)

在这里，你可以查看当前订阅情况，以及资源包中可用与已使用的积分信息。

#### 企业管理员

企业版管理员可以通过企业管理后台查看企业成员的积分使用情况，并管理每个成员的积分额度。

1. 登录 [管理后台](https://copilot.tencent.com/admin/)
2. 进入「用量管理」→「成员用量」，在这里，你可以查看企业中所有成员的积分使用情况，以及资源包中可用与已使用的积分信息。

![alt text](/docs/static/usage1.DF3VoBD7.png)

可查看：

- 团队月固定用量
- 剩余用量
- 用量明细（包含使用模型、客户端、使用时间等）

![alt text](/docs/static/usage2.BbkjCB3l.png)

![alt text](/docs/static/usage3.DhV2ctY_.png)

### 分配用量

> **说明**：每个企业成员默认设置 **2000 积分** 限额，超出后将无法继续使用，需调整额度。

#### 批量调整

1. 勾选需要调整的成员
2. 点击「批量调整」
3. 设置新的配额

#### 单成员调整

选择单个成员，点击**调整限量**。

![批量调整成员用量配额](/docs/static/usage4.Dkp5hUCG.png)

![单成员调整用量限额](/docs/static/usage5.DGyr-xuJ.png)

- **客户端**：会显示用量不足提示

当整个企业的积分消耗完毕，全体成员都无法使用时，可购买「加量包」获取更多积分。

**购买路径**：

```
企业后台 → 用量管理 → 成员用量 → 加量包
```

## 变配与续费

### 扩容（增加许可证）

**操作路径**：

```
企业后台 → 用量管理 → 成员用量 → 许可证
```
![alt text](/docs/static/expand1.Biye66Sf.png)

![alt text](/docs/static/expand2.CN_rEkPO.png)

### 缩容（减少许可证）

企业旗舰版（SaaS）与企业专享版（专有云）支持在订阅期内自助缩容，无需等到续费时再调整。

**操作路径**：

```
企业后台 → 订阅与用量 → 订阅管理 → 席位管理 → 变配席位
```
![订阅管理页的变配席位入口](/docs/static/downsize-seats.CuzSngmT.png)

点击「变配席位」进入购买页「变配」页签后，将变配方向切换为「缩容」，填写希望减少的许可证数量并确认订单。

**生效与退费规则**：

- 缩容提交后**立即生效**，许可证总数即时更新；已分配给成员的许可证不受影响。
- 退费按用量测算，与剩余容量一并处理：
	- 当前未结束的周期：系统按周期剩余时间折算出两个基准——缩容后当前周期**应保有的用量**（缩容后许可证数 × 单许可月度用量 × 剩余时间系数）和**本次最多可退的用量**（本次减少许可证数 × 单许可月度用量 × 剩余时间系数），再结合当前剩余用量分三种情况处理：
	
	
		- **剩余用量较充裕**（高出应保有水平的量超过最多可退用量）：按最多可退用量退费，超出部分在当前周期内仍可继续使用；
		- **剩余用量高于应保有水平**（未超过最多可退用量）：退还高出应保有水平的部分，退后剩余用量回到应保有水平；
		- **剩余用量已不高于应保有水平**：当前周期不退费、不扣量，剩余用量保持不变。确认订单前，页面会展示当前周期的用量变化与计算说明，可核对无误后再提交。
	- 后续未开始的完整周期：减少的许可证对应费用全额退还，不受当前周期是否退费的影响。
- 退款原路退回付款账户，到账时间以支付渠道为准，可在「订单管理 / 账单」中查看退款记录。

**支持范围与边界**：

- 缩容后的许可证数量不能低于版本起购下限（企业旗舰版 1 个、企业专享版 100 个），且不能低于当前已分配给成员的数量。如需缩到更低，请先在「成员管理」中移除部分成员后再操作。
- 订阅剩余时长为 0 天或订单已到期的，不支持缩容，可在续费时调整数量。
- 加量包、赠送资源包独立计期，不受缩容影响。

### 续费

**操作路径**：

1. 进入企业后台首页
2. 或进入：`用量管理 → 成员用量 → 许可证页面`

## 发票管理

企业管理员可以登录企业管理后台查看订单记录：

1. 登录企业管理后台；
2. 在左侧导航栏中，选择 **订单管理**。
3. 点击 **发票管理**，前往腾讯云控制台查看发票，注意请使用企业绑定的腾讯云 uin 登录腾讯云控制台。
