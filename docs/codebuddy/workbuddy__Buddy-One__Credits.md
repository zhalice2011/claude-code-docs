# Buddy One 积分使用说明

Buddy One 积分可在 WorkBuddy、腾讯文档、ima 和腾讯网盘中使用，各产品共享同一份积分余额。本文介绍积分名称、使用资格、消耗场景、积分额度与有效期，以及积分扣减和不足时的处理规则。

## 积分名称与共享规则

Buddy One 积分在不同产品中显示的名称有所不同，但属于同一份积分余额。

| 产品 | 积分名称 |
| --- | --- |
| WorkBuddy | WorkBuddy 积分 |
| 腾讯文档、ima、腾讯网盘 | Buddy One 积分 |

WorkBuddy 积分和 Buddy One 积分是同一份积分，余额实时共享。在任意一个支持的产品中消耗积分后，其他产品的可用余额也会同步减少。

各产品自行提供的积分不属于 Buddy One 积分，仍按原有规则使用。例如：

- 腾讯文档 AI 积分：仅在腾讯文档内使用。
- ima 算力：仅在 ima 内使用。

## 使用资格

WorkBuddy 中可直接使用积分。在腾讯文档、ima 和腾讯网盘中使用 Buddy One 积分，则需要已加入 Buddy One，并关联对应产品账号。

**使用资格不取决于是否开通 Buddy One VIP。** 加入 Buddy One 后，即使使用体验版等非 VIP 套餐，只要已关联对应产品账号，也可以在该产品中使用 Buddy One 积分。

| 用户状态 | WorkBuddy | 腾讯文档 / ima / 腾讯网盘 |
| --- | --- | --- |
| 未加入 Buddy One | 可用 | 不可用 |
| 已加入 Buddy One，但未关联该产品 | 可用 | 该产品不可用 |
| 已加入 Buddy One，已关联该产品（任意套餐版本，包括体验版） | 可用 | 该产品可用 |
| Buddy One VIP，已关联该产品 | 可用 | 该产品可用 |
| 该产品已解除关联 | 可用 | 该产品不可用，其他已关联产品不受影响 |

积分使用资格按产品分别判断。例如，只关联了腾讯文档，则可以在腾讯文档中使用 Buddy One 积分，但不能在 ima 或腾讯网盘中使用。

腾讯会议暂不涉及积分消耗。关联腾讯会议后，可以在 WorkBuddy 中检索会议内容。

## 积分类型与有效期

Buddy One 积分根据获取方式分为套餐基础积分、套餐赠送积分、购买积分和平台奖励积分。不同类型的积分在有效期上有所区别，具体如下。

| 积分类型 | 获取方式 | 有效期 | 能否在已关联产品使用 |
| --- | --- | --- | --- |
| 套餐基础积分 | 套餐按周期发放 | 当前套餐周期结束时失效，不结转至下一周期 | 能 |
| 套餐赠送积分 | 套餐按周期发放 | 当前套餐周期结束时失效，不结转至下一周期 | 能 |
| 购买积分（加量包） | 用户购买 | 独立计算有效期，不随套餐到期失效 | 能 |
| 平台奖励积分 | 邀请、补偿、拉新等运营活动 | 以各活动规则为准 | 能 |

各版本每个套餐周期发放的基础积分和赠送积分如下，积分有效期为一个月。

| 版本 | 基础积分 | 赠送积分 |
| --- | --- | --- |
| 体验版 | 500 | — |
| 标准版 | 2,000 | 2,000 |
| 高级版 | 4,000 | 5,000 |
| 旗舰版 | 20,000 | 30,000 |
| Buddy One VIP | 20,000 | 30,000 |

## 积分扣减顺序

在多个积分包同时有余额时，系统按照积分的到期时间决定扣减顺序，优先扣减最早到期的积分，不按积分类型区分先后。不同产品的扣减规则如下。

### WorkBuddy

所有可用积分按照到期时间从早到晚依次扣减，不区分基础积分、赠送积分、购买积分或平台奖励积分的类型。

示例：当前有两个积分包：A 包剩 300 积分、明天到期；B 包剩 500 积分、下周到期。本次消耗 400 积分，先扣除 A 包的 300 积分，再从 B 包扣除 100 积分。

### 腾讯文档和 ima

- 默认优先使用 Buddy One 积分，扣减顺序与 WorkBuddy 相同。
- 用户也可以选择使用该产品自己的积分（如腾讯文档 AI 积分、ima 算力）。
- 腾讯文档 AI 积分、ima 算力只能在本产品内使用，不能在 WorkBuddy 或其他产品中使用。

### 腾讯网盘

使用 Buddy One 积分，扣减顺序与 WorkBuddy 相同。

## 积分不足与恢复

当 Buddy One 积分全部用完后，不同产品对 AI 功能的处理方式有所不同。部分产品会暂停相关 AI 能力，腾讯文档和 ima 则可以使用本产品已有的积分继续使用相关功能。

| 情况 | 处理方式 |
| --- | --- |
| Buddy One 积分全部用完 | WorkBuddy 和腾讯网盘中的 AI 能力暂停；腾讯文档和 ima 自动使用各自已有的积分继续使用，不受影响 |
| 仍有 Buddy One 积分可用 | 不暂停相关 AI 能力，继续按照扣减顺序消耗积分 |
| 购买 Buddy One 积分 | 购买成功后立即恢复，所有已关联产品均可使用 |
| 进入下一个套餐周期 | 新一期基础积分和赠送积分发放后，相关 AI 能力自动恢复 |

## 查看积分余额与消耗明细

可在[个人中心](https://www.workbuddy.cn/profile/plans-usage)，查看可用积分和消耗明细。

- **可用积分**：剩余总积分，以及基础积分、赠送积分、购买积分、平台奖励积分各自的剩余数量和到期时间。点击剩余积分旁的说明图标，可以看到当前积分能在哪些产品中使用。
- **消耗明细**：每条积分消耗记录都会标注对应的消耗产品，并支持按产品筛选，方便核对不同产品的积分使用情况。
