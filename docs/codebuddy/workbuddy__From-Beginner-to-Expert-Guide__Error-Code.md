# 错误码处理说明

## 如何看对话中的错误提示

任务出错时，对话里会显示一条错误提示，由三部分组成：

- **标题**：说明是什么问题，例如「网络连接失败，请检查网络后重试」；
- **描述**：说明可能的原因和下一步建议；
- **操作按钮**：直接处理的入口，不同错误提供的按钮不同，常见的有：

| 按钮 | 作用 |
| --- | --- |
| **重试** | 重新执行刚才失败的这一步 |
| **切换模型** | 换一个模型后再发送 |
| **检查网络** | 打开网络诊断，排查本机网络 |
| **新建任务** | 内容或上下文有问题时，换一个干净的任务继续 |
| **重新登录** | 登录状态失效时重新登录 |
| **配置模型** | 前往模型配置页补全配置（自定义模型） |
| **提交反馈** | 把问题反馈给我们 |
| **查看文档** | 打开本页，查看对应说明 |

反馈问题时，请把提示里的错误码（如有）或标题一并告诉我们。下面是常见错误码的处理建议。

## 常见错误码

### 1001

- **常见判断**：多与模型侧状态有关。
- **处理方案**：优先切换模型重试。

### 3002

- **常见判断**：网络连接失败，多与网络环境有关。
- **建议处理**：
	1. 先确认当前使用的是公司网络还是家庭网络。
	2. 若为公司网络，建议联系企业 `IT` 协助排查。
	3. 若为家庭网络，可按官网网络排查流程逐项处理。
	4. 也可以参照 [网络代理](#网络代理) 关闭网络代理

**网络波动时的自动处理**：遇到网络问题时，WorkBuddy 会先自动重连，任务进度处显示「网络故障，尝试重连中…」，已生成的内容和执行记录会保留。

如果自动重连没有成功，本轮对话会暂停输出，并显示「持续检测网络状态中」。此时对话末尾会出现一行提示，说明系统将在检测到网络恢复后自动重试，并提供 **查看文档**、**提交反馈**、**检查网络** 入口（具体显示哪些取决于当前环境）：

- 网络恢复后，WorkBuddy 会自动继续刚才的任务，直接接在原来的回复后面，不会新开一轮对话；
- 不想自动继续时，点击提示右侧的关闭按钮即可。关闭后不再等待网络恢复，这一轮会按已结束处理，回复位置显示「网络连接失败」，并保留点赞、重新生成等常用操作；
- 你手动停止任务后，不会自动继续。

### 3003

- **常见判断**：网络连接超时，多与网络环境有关。
- **建议处理**：
	1. 先确认当前使用的是公司网络还是家庭网络。
	2. 若为公司网络，建议联系企业 `IT` 协助排查。
	3. 若为家庭网络，可按官网网络排查流程逐项处理。
	4. 也可以参照 [网络代理](#网络代理) 关闭网络代理
	5. 正在进行下载或上传任务时，可先暂停，或更换到更稳定的网络、切换其他模型。

3003 的自动重连与网络恢复后自动继续的处理方式与 3002 相同，关闭提示后回复位置显示「网络连接超时」。

### 3007

- **常见判断**：多与网络环境有关。
- **建议处理**：
	1. 先确认当前使用的是公司网络还是家庭网络。
	2. 若为公司网络，建议联系企业 `IT` 协助排查。
	3. 若为家庭网络，可按官网网络排查流程逐项处理。
	4. 也可以参照 [网络代理](#网络代理) 关闭网络代理

### 3008

- **常见判断**：本次模型没有返回可用的回答或操作指令，任务暂时无法继续。
- **处理方案**：稍后重试，或切换模型；仍然反复出现请提交反馈。

### 4100

- **常见判断**：当前选择的自定义模型没有配置接口地址或 API Key，请求不会发出。
- **处理方案**：点击提示卡片中的 **前往配置**，补全该模型的接口地址和 API Key 后再使用，详见[模型配置](./Function-Description/Model)。

此类模型在模型选择器里会置灰、不能选中，并标有异常图标，悬停可看到「当前自定义模型未配置接口地址或 API key，请前往配置后使用」及 **前往配置** 入口。补全并保存后，模型即恢复可用，无需重启。

### 6003

- **常见判断**：表示请求频率受限，专业版也可能出现。
- **建议处理**：优先切换模型重试。

### 6004

- **常见判断**：表示请求频率受限，专业版也可能出现。
- **建议处理**：优先切换模型重试。

### 11115

- **常见判断**：输入内容过长。
- **处理方案**：精简输入内容或切换为其他支持更大上下文的模型。

### 11133

- **常见判断**：多与模型侧状态有关。
- **处理方案**：新开会话或切换模型重试。

### 11134

- **常见判断**：多与模型侧状态有关。
- **处理方案**：新开会话或切换模型重试。

### 14003

- **常见判断**：多与模型侧状态有关。
- **处理方案**：优先切换模型重试。
