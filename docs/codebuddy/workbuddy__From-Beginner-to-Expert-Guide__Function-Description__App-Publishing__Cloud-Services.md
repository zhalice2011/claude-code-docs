# 云服务

云服务让[网站应用](./Web-App)和[微信小程序](./Mini-Program)不只能够展示内容，还能保存和管理用户提交的数据。报名、预约、订单等记录，以及用户上传的图片和文档，都会保存在云端，关闭页面或更换设备后仍会保留。

应用还可以按需支持用户登录和数据统计，无需自行搭建数据库、部署服务器或维护运行环境。

![云服务概览](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/cloud-overview.BKsT43NE.png)

不确定是否需要云服务，或需要查询数据、调整设置、排查问题时，可以直接告诉 WorkBuddy。WorkBuddy 会根据当前能力协助处理，并在需要你确认或操作时说明下一步。

## 云服务能力

### 数据库

数据库用于保存报名、预约、订单和打卡等业务记录。需要核对、补录或导出时，可以在「数据」页找到对应的数据表。「函数」和「权限」页则用于了解应用如何处理数据，以及不同用户可以访问哪些内容。

![数据库函数页](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/cloud-database-function.DQI7mEeI.png)

![数据库权限页](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/cloud-database-permission.yK0NJSne.png)

### 身份认证

身份认证用于管理应用的登录方式，支持邮箱、手机验证码和微信登录。邮箱登录支持平台托管发信，也可以自定义发信服务和邮件模板。

在页面开启登录方式，不会自动在应用中添加登录功能。需要用户登录时，直接告诉 WorkBuddy 使用场景和登录方式，让它帮你添加。

![身份认证页面查看登录方式开启状态](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/cloud-auth-status.DyZOSqxR.png)

### 文件存储

文件存储让应用能够保存用户上传的图片和文档，适合作品征集、资料提交和报修等场景。在页面可以新建文件夹，上传单个不超过 20 MB 的文件，用于预置共享资料和分类整理内容。

![文件存储管理页](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/cloud-storage.SK84rwDx.png)

### 数据统计

数据统计用于了解应用的用户增长和注册情况。你可以查看总用户数、新增用户数、注册趋势和用户列表。

![数据统计页面](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/cloud-stats.h2HXcXa7.png)

## 云服务额度

云服务的使用额度由会员版本决定，包含两项：**可开启云服务的应用数**，以及**每个应用每月的资源点**。

| 会员 | 可开启云服务的应用数 | 每个应用每月的资源点 |
| --- | --- | --- |
| 体验版 | 10 个 | 5,000 |
| 标准版 | 30 个 | 25,000 |
| 高级版 | 50 个 | 50,000 |
| 旗舰版 | 99 个 | 150,000 |

关于云服务资源点的说明：

- **按应用计算**：资源点以应用为单位独立发放、独立消耗，一个应用的额度用尽不会影响其他应用。
- **刷新周期**：从应用启用云服务当天起，每一个月为一个周期，周期结束后资源点自动刷新。
- **资源点消耗**：使用数据库、文件存储、用户访问和身份认证等能力时，会消耗云服务资源点。

### 云服务应用名额不足时

你可以选择：

- **释放现有名额**：删除不再需要的应用。删除后会立即释放云服务名额，但关联的数据、文件和注册用户也会被永久删除，无法恢复。
- **增加应用名额**：升级会员版本，获得更多可开启云服务的应用名额。

### 单应用的云服务资源点不足时

资源点即将用完时，可以提前升级会员版本，避免云服务中断。资源点用完后，云服务会进入隔离并停止访问，数据暂不支持导出。你可以选择：

- **升级恢复**：在隔离期内升级会员版本，云服务会立即恢复。
- **等待恢复**：当下一次资源点刷新时间早于隔离期结束时间时，可以等待资源点刷新，届时云服务会自动恢复。

注意

如果资源点无法在隔离期结束前刷新，只能升级会员版本，否则相关云服务数据将被永久删除且无法找回。

隔离期间会员到期或会员版本降低，资源点额度和隔离期会按降级后的会员版本调整，具体以页面最新提示为准。隔离期由会员版本决定：体验版 15 天、标准版 30 天、高级版 30 天、旗舰版 60 天。

## 开启云服务

你可以通过自然语言开启云服务：在创建或修改应用时，说明需要保存什么、谁需要登录，以及是否需要上传文件。WorkBuddy 判断应用需要云服务时，会询问你是否开启，确认后自动完成配置。例如：

```
制作一个宠物健康档案应用。家庭成员登录后可以共同记录并上传检查单，所有内容保存到云端。
```
## 通过 WorkBuddy 使用云服务

你不需要使用数据库或权限规则等技术术语，直接说明想实现的业务结果即可。

应用开始使用后，业务流程和数据管理需求可能发生变化，例如需要保存新的信息、调整自动处理规则、区分不同角色的访问范围，或整理用户上传的文件。遇到这些情况，可以继续告诉 WorkBuddy 需要调整什么，例如：

- 设置权限：“普通用户只能查看自己的记录，管理员可以查看全部记录并审核。”
- 管理文件：“帮我查看用户上传的证明材料，并按活动分类整理。”
- 调整数据：“给报名记录增加审核状态和备注，并保留已有记录。”
- 核对数据：“帮我查看最近一周的报名记录，并找出重复提交的信息。”
- 了解统计：“这个应用最近一周新增了多少用户？”
- 排查问题：“帮我看看最近的报名为什么提交失败，并告诉我可以怎么处理。”

## 管理云服务

需要直接核对数据、用户、文件或服务状态时，可以通过以下两种方式进入云服务管理页：

- 在对话中打开应用预览，点击应用标题旁的「云服务」；
- 进入「设置 \> 数据管理 \> 应用」，点击已开启应用的云服务图标。

![应用预览标题旁的云服务入口](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/webapp-cloud-entry.BYkfGfvj.png)

![数据管理的应用列表中点击云服务图标](https://download.codebuddy.cn/web/docs/58cb23ac03eddfd4f57622ab247bb99af32bf29e/docs/static/cloud-manage-list.CgeYY4Ib.png)

使用和管理云服务时，请注意：

- 预览版和已发布版本使用同一个云服务，预览时提交的测试内容也会进入正式数据。发布前请清理不需要的测试数据。
- 下线应用不会删除云服务数据。删除应用会同时删除关联的数据、文件和注册用户，且无法恢复。

## 常见问题

### 不开云服务，应用还能使用吗

可以。如果应用只用于展示内容，或者数据只需保存在当前设备，可以不开启云服务。不开启云服务不会消耗云服务资源点，也不占用云服务应用名额。需要跨设备保存、多人共享数据、用户登录或上传文件时，再开启云服务。

### 什么会消耗云服务资源点

使用数据库、文件存储、用户访问和身份认证等能力时，会消耗云服务资源点。实际消耗与应用的访问人数和使用情况有关，具体以产品内显示为准。

### 云服务暂停后，数据会丢失吗

如果云服务在隔离期结束前仍未恢复使用，相关云服务数据将被永久删除且无法找回。

隔离期间，云服务无法访问，数据暂不支持导出。如果应用已发布，使用云服务的功能将不可用，其他功能不受影响。

升级会员版本可以立即恢复云服务；如果下一次资源点刷新时间早于隔离期结束时间，也可以等待资源点刷新后自动恢复。

> 隔离期间会员到期或会员版本降低，云服务会按降级后的会员版本执行对应的资源点额度和隔离期，具体以页面最新提示为准。例如，标准版到期降为体验版后，将按体验版的额度和隔离期处理。

### 可以单独关闭云服务吗

目前不支持单独关闭云服务。如果应用名额不足，可以升级会员版本；如果需要释放现有名额，只能删除不再需要的应用。删除应用会同时永久删除关联的数据、文件和注册用户，无法恢复。
