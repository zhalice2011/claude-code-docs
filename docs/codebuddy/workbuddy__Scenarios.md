# 适用场景

WorkBuddy 支持多种工作场景，可用于日常办公、代码开发、设计创意等任务。

## 日常办公

面向日常工作和生活中的信息处理、内容创作、邮件编辑、研究分析与效率提升等场景。

| 场景 | 说明 |
| --- | --- |
| 文档处理 | 创建、编辑、整理和优化各类文档内容，支持批量文件处理。 |
| 金融信息辅助分析 | 辅助处理金融信息、数据和相关业务内容。 |
| 数据分析及可视化 | 对数据进行分析、处理并生成可视化结果。 |
| 个人工作台 | 协助处理个人事务、信息整理和日常工作。 |
| 幻灯片 | 根据需求生成和优化演示文稿。 |
| 深度研究 | 针对复杂主题进行信息检索、分析和整理，输出研究结果。 |
| 视频生成 | 根据文字或创意生成视频内容。 |
| 产品管理 | 辅助进行产品规划、需求分析和产品内容整理。 |
| 最新新闻 | 快速获取和整理最新资讯与新闻信息。 |
| 帮我写作 | 根据主题和要求生成、修改和优化文字内容。 |
| 日常翻译 | 对文本进行翻译、润色和语言转换。 |
| 生活小知识 | 查询和整理日常生活中的实用知识与信息。 |
| 工作技巧 | 提供工作方法、效率提升和问题处理方面的建议。 |
| 旅游攻略 | 根据目的地和出行需求整理行程、景点和旅行建议。 |

### 小程序补充说明

小程序支持通过对话生成，并可直接预览、测试和托管发布。完整操作指引见[小程序开发与发布](./From-Beginner-to-Expert-Guide/Function-Description/Mini-Program)。

- **生成方式**：对话中明确说明“开发微信小程序”或“发布到微信小程序”即可生成；如有数据存储、文件存储、登录认证、数据分析等云服务需求，也可一并说明。
- **预览和测试**：程序生成后，可先在 WorkBuddy 中预览。正式上线前，建议发布体验版并进行真机测试。
- **托管发布**：WorkBuddy 可代为完成代码上传、体验版生成和正式版提审，无需使用微信开发者工具，也无需在微信公众平台操作。
- **发布状态**：点击**分享**后，可在弹窗中查看小程序当前发布状态及正式版审核结果。若审核未通过，可根据微信返回的审核原因修改后重新提交。
- **更新和下线**：修改小程序后，可重新发布新版本。正式版支持下线，下线后用户将无法继续访问。
- **发布后管理**：发布后，依次点击**头像** \> **设置** \> **数据管理**，进入**应用**页签，即可查看和下载小程序码，用于扫码访问和分享。
- **首次发布正式版**：首次发布前，需根据页面提示完成小程序备案、用户隐私保护指引及 UGC 信息安全申明。其中，隐私保护指引填写不完整可能导致审核失败。

发布小程序时，可根据是否已有微信小程序账号选择以下方式：

| 发布方式 | 适用场景 | 可发布版本 | 有效期 |
| --- | --- | --- | --- |
| 创建试用版小程序 | 尚未注册微信小程序账号，希望快速体验 | 试用版 | 14 天 |
| 绑定已有小程序账号 | 已有微信小程序账号，需要真机测试或正式运营 | 体验版、正式版 | 无固定有效期 |

TIP

创建试用版后，暂不支持转正，也无法改为绑定已有账号。如需长期运营，建议注册微信小程序账号并完成绑定。

## 设计创意

面向视觉设计、品牌创意和数字产品设计等场景，生成交互原型、组件设计和布局方案。

| 场景 | 说明 |
| --- | --- |
| 视觉海报 | 根据主题和创意，默认使用 AI 生图快速产出视觉方案和海报设计。 |
| 运营海报 | 制作活动、营销和运营场景所需的推广物料。 |
| PPT 设计 | 将内容整理为具有视觉表现力的演示文稿。 |
| 生成图片 | 根据文字描述生成图片和视觉素材。 |
| 生成视频 | 将创意、文字或图片转化为视频内容。 |
| 品牌设计 | 辅助进行品牌视觉、Logo 和品牌素材设计。 |
| 网站设计 | 规划网站页面结构、视觉风格和界面方案。 |
| 移动端 App | 设计移动端 App 的界面和交互方案。 |
| 设计系统 | 构建设计规范、组件和可复用的设计体系。 |
| Web App | 设计 Web 应用的界面、交互和页面结构。 |
| 图标\&插画 | 通过 AI 生图创建图标、插画等视觉设计素材。 |
