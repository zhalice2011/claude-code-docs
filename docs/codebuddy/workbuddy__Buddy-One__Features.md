# Buddy One 功能说明

开通 Buddy One 后，除获得各产品的会员权益外，WorkBuddy 客户端还将解锁以下专属功能。

## 跨产品搜索

开通 Buddy One 后，可以直接在对话中让 AI 检索你在多个产品中的内容，无需逐个应用查找：

- **多来源检索**：AI 可同时检索 WorkBuddy 资料库、腾讯文档和 IMA 中的内容，并汇总检索结果；
- **来源标识**：每条检索结果都会标注内容来源（资料库 / 腾讯文档 / IMA），点击来源即可跳转到原始内容；
- **使用方式**：跨产品搜索没有独立入口，直接在对话中描述检索需求即可。例如：「帮我搜索所有文档中关于项目交付标准的内容」。

TIP

与客户端左上角的[全局搜索](./../Task-Management#使用全局搜索)（`Ctrl+K`）是两个不同的功能：

- **全局搜索**：检索本地任务、空间、产物和资料库内容；
- **跨产品搜索**：由 AI 在对话中执行，可同时检索 WorkBuddy 资料库、腾讯文档和 IMA 中的内容。
## 注意事项与重点提示

- **账号关联**：各产品的账号关联状态发生变化（如解绑、换绑）时，相关权益的发放可能受到影响，以产品内提示为准；
- **检索范围**：跨产品搜索的检索范围以各产品实际可访问的内容为准，未授权或未同步的内容无法被检索到；
- **版本差异**：以上功能的实际界面与入口位置以客户端最新版本为准。
