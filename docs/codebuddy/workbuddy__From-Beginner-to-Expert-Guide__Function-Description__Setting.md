# 系统设置

WorkBuddy 的设置面板集中管理账号、外观、模型、数据等全部配置项。点击左侧边栏底部的**头像**，在用户菜单中点击**设置**即可打开。

## 一、打开设置面板

点击左侧边栏底部的**头像**，弹出用户菜单，点击**设置**打开设置面板。

![用户菜单](https://download.codebuddy.cn/web/docs/59627aa83a521ce15e8397f23b45ea83b3a15b19/docs/static/user-menu.BeSSfC0s.png)

桌面端的设置会以**独立窗口**打开，不再占用主窗口——主窗口可以继续正常使用，设置窗口内也能自由切换各个设置项。再次点击**设置**会聚焦到已经打开的窗口，不会重复打开多个；关闭设置窗口不影响主窗口和正在执行的任务。

用户菜单浮层同时提供几个快捷入口，可直接进入对应功能：

| 入口 | 说明 |
| --- | --- |
| 企业版 | 进入企业智能体 |
| 查看积分余额 | 查看当前积分余额与明细 |
| 记忆与进化 | 查看与管理记忆，详见[记忆](./Memory) |
| 外观 | 快速切换浅色 / 深色主题 |
| 帮助与反馈 | 帮助文档与意见反馈入口 |
| 检查更新 | 检测当前版本并按提示完成更新 |
| 退出登录 | 退出当前账号，切换其他账号登录 |

## 二、设置面板

设置面板采用**左侧导航 \+ 右侧内容区**结构，左侧为设置项导航，右侧为对应配置内容，**修改即时生效、无需重启**。

![设置面板](https://download.codebuddy.cn/web/docs/59627aa83a521ce15e8397f23b45ea83b3a15b19/docs/static/setting-panel.Cu4oTrre.png)

## 代码开发的用户级配置兼容

进行代码开发时，WorkBuddy 会自动识别并加载你在个人环境中定义的**用户级 `.codebuddy` 配置**，包括规则、技能（Skills）、命令（Commands）、MCP 等：

- 用户级配置与项目级配置按明确的优先级合并生效，互不冲突；
- 配置加载失败时会有清晰提示，且不影响代码开发主流程。

用户级与项目级配置的完整目录说明，见 CodeBuddy Code 的[`.codebuddy` 目录结构说明](/docs/cli/codebuddy-dir)。
