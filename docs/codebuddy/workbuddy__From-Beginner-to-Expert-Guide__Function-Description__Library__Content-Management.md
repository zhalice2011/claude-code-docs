# 内容管理

> 团队中人和 Agent 的产物一起管理，共享上下文。

内容管理解决的是"资料放在哪、谁能找到、Agent 能不能用"的问题。个人产出与团队资料分区存放，各种格式的文件汇入同一棵目录树，任务中还能随时把资料库内容读进来继续加工。

## 个人文档与团队资料，分开整理

打开左侧边栏的**资料库**，界面分为「我的文档」与「团队空间」两块，每一种资料都有明确归属。

### 我的文档

「我的文档」是你的个人空间，也是你和 Agent 共同产物的默认落脚点：

- **自己的地盘** — 可以主动新建目录、手动创建和整理内容，按自己的方式经营
- **接住产物** — 你和 Agent 在会话里一起写的 MD 文档、做的网页，存入资料库后默认先落到这里
- **随时接着干** — 存进来的文档下次还能让 Agent 继续改、继续补，人和 AI 在同一份文档里接力

### 团队空间

项目背景、过程资料和关键结论，统一整理到团队空间。需要更多人一起推进时，把内容从「我的文档」挪进团队空间即可。空间内可以像文件夹一样嵌套整理文档树。

> 团队空间的创建、成员邀请与权限档位详见[多人多Agent 协作](./Collaboration)。

## 把内容存进资料库的两条路径

根据手上产物的形态，有两种方式：

### 在会话中让 Agent 保存

适合和 Agent 一起写的 MD 文档、HTML 网页。在生成该产物的会话中要求 Agent 把内容存入资料库，Agent 会通过资料库能力完成上传，并告知存放位置。会话里有多个产物时，可以指定要保存哪一个。

> 这条路径的好处：不用手动导出再上传，产物直接从"会话里的内容"变成"资料库里可管理的文档"。

### 分享即存入

适合已经生成、准备发给别人看的内容（尤其是网页、报告这类）。在产物上点击**分享**，在**发布**页签中开启**发布为网站**，系统会把它发布为在线链接：对方打开链接就能查看，你自己也能在资料库中找到这份内容。

> 这条路径的好处：发布的动作本身就完成了存入，发出去和存下来一步到位。操作详情见[轻量发布](./Lightweight-Publish)。
> 
> **企业版**的发布范围由企业管理员配置：允许全网发布时，发布的网站无需登录即可访问；仅允许组织内发布时，发布的网站必须登录并以组织内身份校验后才能查看。

## 零散在各处的资料，都能进入同一棵目录树

AI 产物、本地文件和多媒体文件都能放进资料库，不需要在多个工具之间来回搬运。

| 分类 | 支持格式 | 说明 |
| --- | --- | --- |
| AI 三件套 | MD · CSV · HTML | WorkBuddy 任务中最常产出的三种形态，各自承担内容、数据与表达 |
| 办公与本地文件 | PDF · Word · PPT · Excel | 日常办公文档直接上传归档，可在 WorkBuddy 内预览和编辑 |
| 图片、音频与视频 | PNG · JPG · MP3 · MOV | 多媒体素材与资料一同管理，便于后续引用 |
| 压缩包 | ZIP | 作为普通文件保存，可下载、可删除；包含网页内容的压缩包可自行选择转为在线网页，详见下方[上传压缩包](#上传压缩包) |

除了新建和上传，还支持**剪藏网页链接**入库，以及让 Agent 在任务中**直接把产物生成到指定目录或团队空间**，无需二次搬运。放进来的资料可以随时拖拽移动、嵌套归类。

### 上传压缩包

上传 `.zip` 压缩包时，资料库会按普通文件保存，不会再自动解压或转换成网页，也不会因为压缩包的内容类型而上传失败。素材包、备份包、设计稿打包等都可以直接放进目录树，需要时下载使用。

点击资料库中的压缩包，会进入文件详情页，显示「该文件类型暂不支持预览」，点击 **下载文件查看** 即可下载。

**转为在线网页**：如果压缩包里包含网页内容（如 `index.html` 及配套的静态资源），详情页会在「该文件类型暂不支持预览」下方提示「检测到内容包含HTML网页，可转为在线网页后预览、协作」，并提供 **转为在线网页** 按钮；只想下载查看时，点下方的 **下载文件查看** 即可。

![压缩包包含网页内容时，详情页提供「转为在线网页」](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/library-zip-convert-guide.p6EjOeYj.png)

是否转换由你决定：

1. 点击 **转为在线网页**，在确认弹窗中确认：转换会生成一个独立的在线网页，原压缩包仍然保留；
2. 转换完成后，压缩包节点下会出现一个同名的 `.html` 网页，点击即可在线预览、协作；原压缩包仍保留在目录中，可继续下载或删除。

![转换完成后，压缩包下新增可预览的 .html 网页](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/library-zip-converted-tree.PL2E9j2Z.png)

说明

- 不想转换时，不做任何操作即可，压缩包保持原样；
- 包内没有网页内容，或系统无法判断时，该压缩包按普通压缩包处理，不影响上传和下载；
- 不需要原压缩包时，可以在转换后自行删除。
## 任务中直接读取与修改资料库

资料库是 WorkBuddy 的原生能力，可在任务中随时读取、修改资料库内容，**Agent 拥有与人一样的权限**。资料不是一次上传就结束，而是进入持续工作的闭环。

### 从空间或文档添加到任务

- **文件详情页：** 点击所需文档查看详情，在详情页右上方点击 **···** 打开更多菜单，选择**添加到任务**。同一菜单中还可以选择用浏览器打开、投屏展示和查看文档信息。评论的显示与隐藏在评论面板中设置，详见[查看与管理评论](./Collaboration#查看与管理评论)。

![在详情页菜单中选择「添加到任务」](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/add-to-task.Cm81svAS.png)

- **资料库侧边栏：** 在资料库目录中选中空间或文档，点击 **···** 打开菜单，选择**添加到任务**。同一菜单中还可以重命名、复制链接、邀请和管理成员。

![在资料库目录菜单中选择「添加到任务」](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/task-add-to-task.ZmtLAs8j.png)

### 基于资料提问，让 Agent 执行

所选空间进入任务上下文后，直接基于其中的资料提问，让 Agent 执行。因为背景已在上下文中，不必反复解释项目情况。

![所选空间进入任务上下文后直接提问](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/task-run-with-space.DJ9ZA9AU.png)

### 把成果保存回资料库

任务完成后，把新的分析成果直接保存回资料库，后续可以继续查找和调用。

![把任务成果保存回资料库](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/task-save-to-library.DTsNhJKl.png)

> 这个闭环让历史成果可以被后续任务反复利用：下一次分析时 Agent 直接读取已沉淀的资料，沿着已有结论继续，而不必从零开始，也不需要翻找历史会话。

## 查看 HTML 产物

查看 HTML 产物时，**更多（…）**菜单提供刷新、页面查找、缩放和截图等工具。

### 刷新

通过**更多（…）→ 刷新**重新加载当前产物，无需关闭后重新打开。在线产物和本地文件的入口略有差异，分别说明如下。

#### 在线 HTML 产物

在资料库中打开在线 HTML 产物，在该产物的工具栏中点击**更多（…）**，选择**刷新**。

![在线 HTML 产物的更多菜单中选择刷新](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/html-refresh-online.A4PW1LM5.png)

#### 本地 HTML 文件

预览本地 HTML 文件时，在预览界面的工具栏中点击**更多（…）**，选择**刷新**。

![本地 HTML 预览的更多菜单中选择刷新](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/html-refresh-local.DDCmIQrk.png)

刷新后页面会回到该 HTML 的入口页顶部，已进入的子页面及打开的弹层等会一并重置。刷新只作用于当前 HTML，不会返回 WorkBuddy 首页，也不会切换到其他标签页。

### 查找、缩放与截图

HTML 产物的**更多（…）**菜单中，还提供以下页面工具，用法与[右侧边栏中的内置浏览器](./../Right-Sidebar)一致：

| 菜单项 | 说明 |
| --- | --- |
| **查找页面内容** | 在当前页面中查找关键词，可在匹配项之间跳转；也可按 `Cmd+F` / `Ctrl+F` 打开 |
| **显示设备工具栏** | 切换手机 / 平板 / 桌面等视口，查看页面在不同设备下的效果 |
| **缩放** | 点击 **−** / **\+** 缩小或放大页面，点击重置按钮恢复原始大小 |
| **截取屏幕截图** | 截取当前页面可视区域，并复制到剪贴板 |

缩放也可使用 `Cmd` / `Ctrl` 加 `+`、`-`、`0`，使用触控板时还可以双指捏合放大页面局部细节。

## 本地 HTML 可视化编辑

打开本地 HTML 产物，可直接在预览界面进行可视化编辑，人和 AI 在同一份网页上接力，不必事事回到对话：

**手动编辑**——选中元素后通过悬浮菜单直接调整，即时生效：

| 元素类型 | 可执行操作 |
| --- | --- |
| 文本（标题 / 正文 / 列表 / Badge / 引用 / 链接） | 字体、字号、加粗、斜体、下划线、删除线、颜色 |
| 图片 | 替换、裁剪、加边框 |

**AI 编辑**：

- 选中任意元素即可唤起 AI 编辑，输入指令后由 AI 完成修改；静态元素与 JS 动态生成字段全覆盖；
- JS 动态生成的元素受保护：悬浮菜单只提供 AI 编辑入口，不提供样式类手动按钮，避免破坏动态逻辑；
- AI 编辑指令可「插入到输入框」（`Enter`）继续补充，或「发送到对话」（`Ctrl / Cmd + Enter`）直接执行；
- AI 改完后预览自动刷新，不额外出现审阅卡片或 diff 对比界面。

**撤销与重做**：连续编辑操作可逐步撤销、重做，放心试改。

![本地 HTML 可视化编辑](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/html-visual-editor.co2vInlt.png)

## 本地 Markdown 编辑器

打开本地 Markdown 产物，除手动与 AI 编辑外，还提供以下编辑辅助能力：

### 划词菜单

选中文本即弹出菜单，简单格式化自己动手、即时生效，不用再绕给 AI：

- 菜单按钮：**AI 编辑**｜**加粗** / **斜体** / **下划线** / **删除线** / **链接** / **行内代码**
- 点击即时生效；复杂的内容调整仍可交给 AI 编辑

![划词菜单](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/md-editor-selection-menu.CPvzmiPs.png)

### 悬浮快捷菜单

鼠标悬停在表格、图片、代码块等内容块上时，会浮出对应的专属操作菜单：

| 内容块 | 专属操作 |
| --- | --- |
| 列表 | 继续编号、重新编号 |
| 表格 | 新增 / 删除行列，长按列头拖拽调整列序 |
| 代码块 | AI 编辑、切换语言、复制代码、删除 |
| Mermaid 图表 | AI 编辑、切换视图、复制代码、下载图表 |
| 图片 | AI 编辑、全屏查看、下载、删除 |
| 视频 / 文件 | AI 编辑、预览 / 全屏、下载、删除 |
| 链接 | 打开、复制、编辑、取消链接 |

![链接悬浮菜单示例](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/md-editor-hover-menu.Gf63krE9.png)

说明

撤销 / 重做无显性按钮，统一使用系统快捷键：`Ctrl / Cmd + Z`（撤销）、`Ctrl / Cmd + Shift + Z`（重做）。编辑结果存入资料库后，云端渲染效果与本地一致。

### 文档目录导航

写长文档不用再靠滚动条找章节：

- 鼠标**悬停正文右侧**即展开**目录浮层**，文档标题按 H1\~H6 层级缩进展示，正文标题增删改时**实时同步**；
- **点击目录节点**跳转到对应章节；
- 滚动正文时，目录会**自动高亮**当前所在章节；
- 文档没有标题时不显示目录入口。

![文档目录导航](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/md-editor-toc.C0a_I6xz.png)

### 查找与替换

在文档中按 `Cmd+F` / `Ctrl+F` 打开查找面板，输入关键词后可在匹配项之间逐处跳转；按 `Cmd+H` / `Ctrl+H` 则直接进入「查找 \+ 替换」。

- 面板显示当前命中位置与总数，可开关「区分大小写」；
- 替换可只替换当前一处，也可**全部替换**；
- 文档处于只读状态时只能查找，不能替换；
- 按 `Esc` 或点击关闭按钮收起面板。

![本地 Markdown 的查找与替换面板](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/md-editor-find-replace.DMuhlFTj.png)

提示

`Cmd+F` / `Ctrl+F` 在对话区搜索的是对话内容；焦点在文档里时，同样的快捷键查找的是当前文档。

### 内容缩放

点击预览区的**更多**菜单，在「缩放」一行用 **−** / **\+** 缩小或放大文档内容，点击重置按钮恢复原始大小。缩放只作用于文档内容，不会改变客户端界面和字号。

![本地 Markdown 预览「更多」菜单中的缩放](https://download.codebuddy.cn/web/docs/f64731d6a6e5561e764ce1a54a3a6b996c36297d/docs/static/md-editor-zoom-menu.B5M5yXGo.png)

也可以在光标位于文档内时，用 `Cmd` / `Ctrl` 加 `+`、`-`、`0` 缩放，或按住 `Cmd` / `Ctrl` 滚动鼠标滚轮。使用快捷键或滚轮缩放时，预览区顶部会短暂浮出缩放提示，可直接点击其中的按钮继续调整。

### 智能复制

在 md 编辑器中按 `Ctrl / Cmd + C` 复制，内容会自动适配粘贴的位置：

| 粘贴到 | 效果 |
| --- | --- |
| md 编辑器 | 内容最高保真还原（含格式、评论、高亮等） |
| Word / 飞书 / Gmail 等富文本应用 | 标题、加粗、列表等样式保留，不出现 `##`、`**` 等 md 符号 |
| 记事本 / 搜索框等纯文本场景 | 得到干净的纯文本，列表结构保留（`1.`、`-`、`[x]` 等标识） |

## 使用建议

- 添加到任务时优先选择目录或空间而非逐个选文件，Agent 能获得更完整的上下文
- 任务产出的关键成果及时保存回资料库，形成可累积的资料底座
- 目录结构建议按「项目 → 阶段 → 任务」层级组织，长期更易维护
- 需要多人协作的内容尽早挪进团队空间，避免后续搬运
