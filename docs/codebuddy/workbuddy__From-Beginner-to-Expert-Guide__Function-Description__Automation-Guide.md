# 定时任务

配置定时任务，WorkBuddy 会按设定的时间自动执行周期性、重复性工作（如每日简报、周报汇总、定时数据整理），并集中保存每次运行的结果与产物。

## 概述

定时任务保存任务名称、提示词、执行时间、工作空间、权限等配置，到达执行时间后以您当前的登录身份自动发起任务，按提示词完成查询、汇总、文件处理等工作。任务仅在设定的时间规则触发时执行，受任务频率、最大执行时长与系统并发控制限制。

定时任务分为三种来源：

| 来源 | 说明 |
| --- | --- |
| **本地** | 在电脑端创建，在本机客户端执行 |
| **项目** | 在项目中创建，需前往对应项目查看和管理 |
| **云端** | 在云端沙箱中执行，无需电脑在线；卡片上带云端标识 |

## 打开定时任务

点击左侧导航栏的 **定时任务**，进入定时任务页面。页面分为两个标签页：

- **定时任务**：查看和管理全部任务，首次进入时会推荐常用任务模板。
- **运行记录**：查看所有任务的历次运行情况。

![左侧导航栏的定时任务入口](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-entry.uAPrbN_G.png)

## 创建定时任务

点击页面右上角的 **新建**，可直接手动创建；点击旁边的下拉箭头，可选择以下三种方式：

| 方式 | 适用场景 |
| --- | --- |
| **手动新建** | 需要精确指定执行时间、权限和推送渠道 |
| **从任务新建** | 用一句话描述需求，由 WorkBuddy 帮你创建 |
| **从模版新建** | 不确定能做什么，想从常见场景快速上手 |

![定时任务列表与「新建」下拉菜单](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-new-menu.dlgvaOLy.png)

### 手动新建

在弹出的编辑窗口中填写以下配置，**名称**和**提示词**填写完成后才能点击 **确定**：

| 配置项 | 说明 |
| --- | --- |
| **名称** | 用于区分不同的定时任务 |
| **提示词** | 描述任务目标和输出要求 |
| **模型、专家、技能、连接器** | 在提示词输入框底部选择；点击 **\+** 可添加专家、技能和连接器 |
| **工作空间** | 指定任务执行目录及文件保存位置，详见下方[任务在侧边栏中的位置](#任务在侧边栏中的位置) |
| **权限** | 默认权限或完全访问权限，详见下方[执行权限](#执行权限) |
| **重复** | 执行频率，可选间隔、单次、每天、每周、每双周、每月、每年 |
| **时间** | 每次执行的具体时间 |
| **有效期** | 任务生效的日期范围（单次任务无需设置） |
| **消息推送到企业微信** | 任务完成后将结果推送到企业微信，详见下方[推送到企业微信](#推送到企业微信) |

![新建定时任务编辑窗口](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-create-dialog.D4IM2z-F.png)

**重复规则说明：**

- **每周 / 每双周**可同时选择多个星期，例如每周一、三、五执行；
- **每月**可同时选择多个日期，例如每月 1 日、15 日执行；
- 同一任务的多个执行日期请在一条规则中配置，不要拆成多个定时任务。

### 从任务新建

选择 **从任务新建** 后，WorkBuddy 会回到首页，并在输入框中预填「帮我创建一个定时任务：」。在后面补充具体需求并发送，例如：

> 帮我创建一个定时任务：每个工作日早上 9 点，整理昨天的销售数据，发到产品群

WorkBuddy 会根据描述自动创建定时任务，对话中会展示创建结果，可点击跳转查看任务详情。

提示

在普通对话中直接描述周期性需求（如「每天早上 8 点提醒我…」），WorkBuddy 同样会帮你创建定时任务。

### 从模版新建

选择 **从模版新建**，或在空白页面点击推荐的任务模板（如每日 AI 新闻推送、每周工作周报、会议前准备等），编辑窗口会自动填好名称、提示词和执行时间，按需修改后点击 **确定** 即可。

![定时任务模板](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/auto-3.hygxPDZL.png)

## 管理定时任务

### 查看与筛选

在 **定时任务** 标签页中：

- 按状态筛选：**全部**、**已启用**、**已暂停**；
- 点击 **筛选** 按任务来源（本地 / 项目 / 云端）筛选；
- 点击搜索图标，按任务名称或运行记录搜索。

每张任务卡片会显示执行规则和下一次执行时间。上一次运行失败的任务，标题旁会出现红色失败标识，悬停可查看原因。

### 常用操作

| 操作 | 方式 |
| --- | --- |
| **立即运行** | 点击卡片上的运行按钮，立即执行一次，不影响原有计划 |
| **编辑** | 点击卡片上的编辑按钮，修改任务配置 |
| **暂停 / 开启** | 切换卡片右侧的开关；暂停只影响后续执行，正在运行的这一次不会中断 |
| **查看运行记录** | 点击卡片的 **更多（⋯）→ 查看运行记录** |
| **打开任务** | 点击卡片的 **更多（⋯）→ 打开任务**，进入该任务的运行页面 |
| **删除** | 点击卡片的 **更多（⋯）→ 删除**，删除后任务不再执行，此操作无法撤销 |
| **批量管理** | 点击右上角 **批量管理**，勾选多个任务后统一删除 |

项目任务

项目中创建的定时任务在这里只能查看，编辑、暂停等操作需前往对应项目。

### 任务在侧边栏中的位置

本地定时任务在左侧导航栏中只占用**一个入口**（带定时任务图标），历次运行不会各自生成一条任务：

- **未选择工作空间**：入口出现在左侧 **任务** 列表中；
- **选择了工作空间**：入口出现在对应 **空间** 下。

点击入口即可进入该任务的运行页面。

## 查看运行结果

### 任务运行页面

点击本地任务卡片（或侧边栏中的定时任务入口），进入该任务的运行页面：

- 历次运行按时间线展示，最新一次位于最下方，可查看每次运行的状态、摘要和产物；
- 页面会默认打开最新一次运行的产物，也可以点击其他产物切换查看；
- 顶部显示下一次运行时间，并可直接运行、暂停 / 开启、编辑任务或查看运行记录；
- 点击某次运行可进入对应会话，查看完整执行过程并继续对话。

### 运行记录

在 **运行记录** 标签页中，可查看所有定时任务的历次运行，包括任务名称、状态、运行时间、耗时和任务类型：

- 可按状态（成功 / 失败 / 运行中）、任务类型（本地 / 项目 / 云端）和具体任务筛选；
- 运行失败时，点击记录可查看失败原因和处理建议，例如连接器未授权、登录已失效、电脑离线导致错过执行时间等；
- 不再需要的记录可以归档或删除，已归档的记录可在 **设置 → 数据管理** 中查看。

### 结果通知

- **电脑端通知**：开启 **设置 → 通用 → 定时任务产物通知** 后，定时任务生成产物时会通过系统通知提醒你，点击通知即可打开对应产物。
- **手机端通知**：如果 WorkBuddy App 已关联当前电脑，定时任务完成、待确认或失败时，App 也会收到通知，标题以「定时任务：」开头。

## 执行权限

| 权限 | 说明 |
| --- | --- |
| **完全访问权限（推荐）** | 任务无人值守执行，工具调用无需逐次确认；开启时需再次确认 |
| **默认权限** | 敏感操作需要你确认；如果你不在电脑前，任务会停在等待确认状态 |

注意

本地定时任务在本机客户端中执行，执行期间请勿关闭电脑或退出客户端，否则任务可能中断。

## 推送到企业微信

在编辑窗口中打开 **消息推送到企业微信**，任务完成后会把结果推送到企业微信。推送使用助理已绑定的企业微信机器人。

### 开启推送

1. 在新建或编辑窗口左下角，打开 **消息推送到企业微信** 开关。

![新建定时任务窗口中的「消息推送到企业微信」开关](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-wecom-switch.CcFKNX4c.png)
2. 如果助理已通过 **WebSocket 长连接** 绑定企业微信机器人，开关会直接开启，无需其他操作。
3. 如果尚未绑定，开关旁会弹出「尚未连接企业微信机器人，请先完成连接」的提示：

![尚未连接企业微信机器人的提示](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-wecom-not-connected.DfGzUihU.png)

	- 点击 **取消**：开关恢复为关闭；
	- 点击 **连接**：打开「连接企业微信机器人」窗口。
4. 在「连接企业微信机器人」窗口中点击 **获取企业微信二维码**。

![连接企业微信机器人窗口](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-wecom-connect-dialog.DyJCLuyq.png)
5. 使用企业微信扫描二维码，完成机器人接入。没有企业微信账号时，可点击二维码下方的 **去注册**。

![企业微信扫码接入智能机器人](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-wecom-qrcode.D85jFTpZ.png)
6. 绑定成功后会提示「绑定成功，还差一步」。请打开企业微信，向这个机器人发送任意一条消息，完成最终确认，然后点击 **已发送**。

![绑定成功，还差一步](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-wecom-last-step.CYZYD0N_.png)

![在企业微信中向机器人发送任意消息](https://download.codebuddy.cn/web/docs/b1bdb4b45aa8d7c1620a6777830b2dd977252d0e/docs/static/automation-wecom-bot-chat.CU_YwKLj.png)
7. 点击 **已发送** 或 **下次再说** 后会自动回到定时任务，推送开关自动打开，已填写的任务内容不会丢失。

注意

没有在企业微信里给机器人发送过消息时，定时任务找不到接收推送的对象，结果无法推送。绑定后请务必完成第 6 步。

### 已使用 URL 回调连接的情况

定时任务推送只支持 **WebSocket 长连接**，不支持 URL 回调方式。如果助理当前是用 URL 回调连接的，开启开关时会提示「URL 回调连接暂不支持消息推送，需解绑后重新连接」：

- 点击 **重新连接**：会自动取消现有的 URL 回调连接，并提示「已自动帮你取消 URL 回调连接，请重新连接」，然后按引导重新连接；
- 在「连接企业微信机器人」窗口中，从定时任务进入时 **更多连接方式** 里的 URL 回调不可选，悬停会提示「定时任务消息推送不支持 URL 回调配置」。

注意

取消 URL 回调连接后，助理在企业微信里原来通过 URL 回调接收消息的能力也会随之断开，重新连接后改为 WebSocket 长连接方式。

### 其他说明

- 之前已经使用「独立的企业微信机器人」推送的定时任务，保持原有推送方式不变；
- 推送失败不会影响任务本身的执行。

## 云端定时任务

云端定时任务在云端沙箱中执行，电脑关机或离线时也能按时运行，可在客户端中与本地任务一样查看、编辑、暂停 / 开启、立即运行和删除：

- 编辑时不需要选择工作空间和权限，也不支持推送到企业微信；
- 云端沙箱无法访问本机文件，请勿在提示词中引用本地文件路径；
- 删除云端任务后，已经产生的云端会话仍会保留，可继续查看过程与产物；
- 离线时云端任务只能查看，联网后才能操作。

## 注意事项与重点提示

### 信息收集与使用

- 账户身份信息：识别任务归属，触发时沿用当前登录身份调用模型、工具、MCP 和连接器。
- 用户输入内容：保存任务名称、提示词和执行规则，触发时作为任务执行指令。
- 使用行为日志：任务的创建、启停、触发、执行结果与耗时，用于状态展示与审计。
- 第三方平台凭证：仅当任务调用 MCP、连接器或 OAuth 服务时使用您已授权的凭证；定时任务本身不另存凭证。
- 本地文件读写：仅在您指定的工作目录范围内访问。

### 积分消耗提醒

积分消耗视任务复杂度而定：

- 简单提醒类较低
- 代码巡检、文档汇总、连接器分析等可能产生较多 token 消耗

### 第三方共享

定时任务调用外部模型、MCP、连接器、OAuth 平台或通知通道时发生数据共享。

### 安全提醒

任务在无人值守下自动执行，**请审慎设置涉及文件写入 / 删除 / 资金操作的提示词**。

### 使用建议

- 新建任务后建议**先点击运行试跑一次**，确认执行结果符合预期，再放大执行频率。
- 大模型在执行过程中可能存在理解偏差或非预期行为，对**结果中涉及文件改动、数据变更、对外发送的部分，请保留可追溯的日志**，便于核查。
- 任务调用的第三方服务由其独立提供，相关稳定性、计费规则与处理结果**请关注该第三方的服务状态与协议**。
