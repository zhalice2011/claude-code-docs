# 灵感

不知道从哪里开始？打开**灵感社区**，浏览 WorkBuddy 官方及社区贡献的精选案例。你可以按场景浏览、搜索和收藏案例，也可以通过**做同款**复用优秀案例，快速生成自己的成果。

## 灵感和 Skill、专家的区别

Skill 和专家是 WorkBuddy 的能力配置，灵感则是利用这些能力完成的实际案例与成果。

| 模块 | 定位 | 解决的问题 |
| --- | --- | --- |
| Skill | 技能 | WorkBuddy 如何完成某类任务 |
| 专家 | 专业角色与能力配置 | 使用什么专业能力协助完成任务 |
| 灵感 | 案例与成果 | 可以参考什么案例，以及如何复用 |

## 关于灵感

- **使用场景全覆盖：** 精心打磨的丰富场景，覆盖日常和工作中的高频需求，按需挑选，无需从零定义。
- **一键复刻，告别空白页：** 选中喜欢的案例，系统自动预填 Prompt、加载关联的 Skill 和专家配置，直接生成你的专属版本。
- **节省 Token，更高性价比：** 精调案例上下文，减少冗余消耗，提升生成质量。让每一个 Credit 都花在刀刃上。
- **社区智慧沉淀：** 复用高手经验，快速掌握场景化最佳实践。

## 浏览与搜索灵感

在左侧边栏点击**更多**，进入**灵感社区**，即可浏览精选案例。

你可以随机浏览热门案例，也可以按场景分类筛选，或通过关键词搜索快速定位目标案例。搜索支持匹配标题、正文、关联产物名称、专家和 Skill 等内容。

灵感卡片会展示**灵感名称、作者头像与昵称**，方便你在进入详情前了解案例来源。

![](https://download.codebuddy.cn/web/docs/d454fd22dca4c6533cee7077ccb55bed211bf61b/docs/static/inspiration-community-home.BH90tWvZ.png)## 查看灵感详情

点击灵感卡片进入详情页，页面默认采用双栏布局：

- **左侧产物区**：展示灵感关联的产物，支持预览 Miora 画布等类型。默认按可预览产物 \> 对话详情 \> 封面 \> 缺省图优先级展示内容。
- **右侧信息区**：展示灵感案例的点赞数、收藏数等基础信息，以及场景、关联的专家和提示词（Prompt）。
- **右上方工具栏**：提供喜欢、收藏、复制口令、最大化预览、我要反馈等操作。

![](https://download.codebuddy.cn/web/docs/d454fd22dca4c6533cee7077ccb55bed211bf61b/docs/static/inspiration-detail-page.BH4qETST.png)### 基础信息说明

- **点赞数**：统计当前有效的点赞数量。
- **收藏数**：统计当前有效的收藏数量。

### 预览产物

如果需要更清楚地查看产物的页面布局或内容细节，可点击右上方工具栏中的**最大化预览**，放大产物进行查看；再次点击即可还原。

### 切换语言

如需切换界面语言，可点击**切换语言**按钮，选择所需的界面语言。

## 复用灵感

### 做同款

如果希望参考某个案例，在灵感卡片详情页点击右下方的**做同款**，即可基于原案例生成符合自己需求的新成果。

WorkBuddy 会自动填入相关 Prompt，并加载关联的 Skill 和专家配置。你可以直接开始生成，也可以根据实际需求调整指令和细节。

将灵感产物添加到对话时，WorkBuddy 会同时安装该作品关联的专家和技能。

做同款会沿用原案例的版式结构，减少从零生成时的自由发挥，有助于降低生成偏差、节省积分并提升结果的稳定性。

![](https://download.codebuddy.cn/web/docs/d454fd22dca4c6533cee7077ccb55bed211bf61b/docs/static/explore-3.B-b95Qd6.png)TIP

这种方式复用的是案例的生成方案，而不是直接使用原案例的产物。即使修改了部分指令，仍然属于复用生成方案。

### 复用部分成果

如果不需要重新生成案例，只希望将其中的文件或链接用于其他工作，可以直接将产物添加到任务。

1. 在灵感详情页点击**相关产物**右侧的「...」按钮。
2. 选择添加**全部添加到任务**或**单个产物**，文件类产物将作为附件添加，链接类产物将作为链接挂载到任务中。
3. 添加成功后进入对应任务，继续补充指令或开展后续处理。

如果发送失败，WorkBuddy 会停留在详情页并保留失败原因，方便你查看原因后重试。

## 查看生成成果

生成完成后，可在右侧的**产物**页面查看生成结果。若生成的是网页文件，WorkBuddy 会自动打开内置浏览器，方便预览页面效果。

![](https://download.codebuddy.cn/web/docs/d454fd22dca4c6533cee7077ccb55bed211bf61b/docs/static/explore-4.COhbkeGJ.png)## 收藏灵感

看到喜欢的案例，在灵感卡片详情页右上方工具栏点击**收藏**按钮，即可将案例加入个人收藏，方便后续查找和复用。

收藏后，可在**灵感社区**首页，点击右上角的**个人收藏**查看已收藏的灵感。

![](https://download.codebuddy.cn/web/docs/d454fd22dca4c6533cee7077ccb55bed211bf61b/docs/static/inspiration-personal-favorites.Wotttw_c.png)## 分享灵感

如果希望将某个案例分享给同事或其他用户，可以使用**复制口令**功能。

1. 在灵感卡片详情页右上方工具栏找到「...」按钮，点击**复制口令**。
2. 将复制的口令发送给需要查看的人。
3. 对方使用该口令后，即可直达对应的灵感详情页。

## 提交反馈

如果发现灵感案例内容有误、产物存在问题，或希望改进案例内容与使用体验，可以通过**我要反馈**提交问题或建议。

1. **打开反馈弹窗**：在灵感详情页右上方工具栏中，点击「...」，再选择**我要反馈**。
2. **填写反馈信息**：填写联系方式和反馈内容，并根据需要上传相关截图。
	- **联系方式**：填写用于联系的邮箱或手机号。
	- **反馈内容**：描述遇到的问题或改进建议，最多 2000 字。粘贴的内容包含图片时，系统会自动上传图片，并将其作为反馈图片。
	- **相关截图**：支持点击上传图片，最多上传 5 张。

![](https://download.codebuddy.cn/web/docs/d454fd22dca4c6533cee7077ccb55bed211bf61b/docs/static/inspiration-feedback-dialog.DSXmQq25.png)3. **提交反馈**：确认填写的信息后，点击**提交反馈**。

## 注意事项与重点提示

### 信息收集与使用

- **浏览本身：** 不收集个人信息、不调用本地权限。
- **「做同款」衍生：** 触发 Skill / 专家时，按所触发模块的边界处理。

### 积分消耗提醒

浏览不涉及积分消耗；「做同款」以实际触发的功能模块为准。

### 第三方共享

浏览不涉及；灵感衍生行为以实际触发模块为准。

### 免责声明

**灵感**展示内容仅作示例参考，请结合实际场景独立判断后再使用。

### 使用建议

- 探索内容由产品或社区贡献，**不代表 WorkBuddy 对其立场、真实性、准确性的背书**，请您审慎参考。
- 使用「做同款」复现案例时，请关注所触发 [Skill](./Skills-Market) / [专家](./Expert-Center)的能力边界与权限申请。
