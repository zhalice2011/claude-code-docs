# 帮助与反馈

遇到使用问题时，可以先查阅帮助文档；如果仍无法解决，可以使用智能诊断辅助排查，或通过意见反馈提交问题或建议。

## 打开意见反馈

可以通过以下任一入口进入**意见反馈**窗口。

- 方式一：点击左下角头像，在用户菜单中点击**意见反馈**。
- 方式二：点击左下角头像打开**设置**，在左侧导航底部点击**获取帮助**，再点击右侧意见反馈的**填写反馈**。

![意见反馈窗口](https://download.codebuddy.cn/web/docs/a2b1163fb126ec6f3bf00e80c52246a330059206/docs/static/feedback-smart-diagnosis-3.Y9f3P89Q.png)

## 使用智能诊断

当 WorkBuddy 出现功能异常、操作失败或执行结果与预期不符时，如果希望先排查问题原因并获取解决建议，可以在**意见反馈**窗口中描述问题，再点击**智能诊断**。

![意见反馈窗口中点击智能诊断](https://download.codebuddy.cn/web/docs/a2b1163fb126ec6f3bf00e80c52246a330059206/docs/static/feedback-smart-diagnosis-1.DPFHBqf3.png)

WorkBuddy 会自动跳转到智能诊断页面，根据页面提示完成问题排查后，智能诊断会分析问题原因并给出解决建议。诊断过程中填写的答复会自动同步回写到关联记录。

![智能诊断分析结果](https://download.codebuddy.cn/web/docs/a2b1163fb126ec6f3bf00e80c52246a330059206/docs/static/feedback-smart-diagnosis-2.CP0DhCfu.png)

TIP

智能诊断是辅助排查能力，不会替代原有的反馈提交流程。

## 查找使用帮助

需要了解功能用途、操作步骤或具体使用方法时，可以查阅在线帮助文档。点击左下角头像进入**设置**，在左侧导航底部点击**获取帮助**，再点击右侧的**查看文档**，即可打开在线帮助文档。

## 填写反馈

如果希望将问题提交给团队跟进，或需要提出功能优化建议，可以在**意见反馈**窗口中，描述遇到的功能故障、操作异常等问题，也可以提出新增功能、优化现有能力等建议。请根据实际情况描述反馈内容，尽量提供具体的使用场景和相关信息，帮助团队理解并处理。

- **反馈问题**：描述问题现象、触发问题的操作步骤，以及预期结果与实际结果的差异。建议上传相关截图，并勾选上传日志，帮助团队定位问题。如果暂时无法判断问题原因，可以先使用智能诊断辅助排查。
- **提出需求**：说明实际使用场景、当前遇到的不便，以及希望实现的效果。必要时可以上传相关截图，帮助团队理解需求。

填写完成后，点击**提交反馈**，即可提交问题或需求建议。
