# 多人多 Agent 协作

在资料库的团队空间中，成员和 Agent 可以共同管理资料、讨论内容并协作编辑。你可以设置成员权限，并根据内容类型选择 MD 文档审阅、HTML 页面协同编辑或 CSV 数据维护。

## 建立团队空间与设置权限

创建团队空间后，可以邀请成员加入，并根据协作需要设置访问权限。成员和 Agent 在团队空间中的资料访问范围，都由这些权限控制。

### 创建团队空间

在资料库左栏「团队空间」区可以找到你所在的团队，点击标题右侧的 **\+** 新建空间，用于一个项目、一个小组或一条业务线。空间内可以像文件夹一样嵌套整理文档树。

往空间里放资料有四种方式：

- **新建文档或表格** — 直接在空间里写纪要、方案，或建一张 CSV 维护清单与排期
- **上传本地文件** — 把 PDF、图片等文件收进空间
- **剪藏网页链接** — 把文章或网页链接收录进来
- **让 Agent 直接生成到这里** — 在任务中指定生成到某个团队空间，产物即刻落进空间，无需二次搬运

TIP

建议按项目、小组或业务线建立团队空间，并根据实际协作范围设置成员权限。

### 邀请成员与设置权限

在空间菜单中选择**邀请和管理成员**，打开分享面板：可以查看当前协作成员，通过**复制链接**邀请他人加入，也可以分享到微信等渠道或生成二维码。

![分享空间面板：查看协作成员并复制邀请链接](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/team-space-permission.mRiGW7qR.png)

成员权限分为四档，按角色灵活授权：

| 权限档位 | 可做的事 |
| --- | --- |
| 查看 | 浏览空间内容，不能修改 |
| 编辑 | 在空间内新建、修改和整理内容 |
| 管理 | 管理空间成员与权限设置 |
| 无权限 | 不可访问该空间 |

获得链接的人可以单独设定访问方式（如需申请权限、可查看等）。空间默认不对外公开，确需发布给外部访问时再主动开启，公开范围始终由自己掌握。

企业版权限范围管控

企业版下，协作范围由企业管理员统一配置：

- 允许**组织外协作**时：任何人使用 WorkBuddy 账号登录后，均可通过链接加入文档或空间协作；
- 仅允许**组织内协作**时：分享面板的分享范围默认为「组织内」，只有组织内账号登录后才能通过链接加入，无法邀请组织外账号。
### Agent 在团队空间中的协作

将团队空间或其中的文档带入任务后，Agent 就可以基于当前用户有权访问的资料参与协作，协助整理资料、回答问题或修改内容。Agent 沿用当前用户在团队空间中的权限，无需单独配置；当前用户无法访问的内容，Agent 也无法读取。

![Agent 在任务中按当前用户权限读取空间内容](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/task-run-with-space.DJ9ZA9AU.png)

### 让 Agent 在内容里 @ 成员

在任务中让 Agent 起草或修改资料库内容时，可以同时指定需要提醒的成员。Agent 会根据当前账号的权限，在 MD 文档、HTML 页面或 CSV 表格中写入对应的 @ 提及。

匹配成功后，提及会显示为可点击的内容，被提及者会收到通知，通知中会标明由哪个用户的 WorkBuddy 发起。Agent 再次读取内容时，也能识别已有的 @ 提及。可 @ 的对象仅限当前账号有权访问的文档协作者和通讯录人员；如果没有匹配到成员，名称会作为普通文字保留，不影响内容创建和编辑。

## 在 MD 文档中通过审阅模式协同编辑

在 MD 文档中，成员可以通过划词评论围绕具体内容讨论，也可以让 AI 结合评论和正文上下文生成修订建议。AI 不会直接覆盖原文，修改需经你审阅并接受后才会写入正文。

### 划词评论与讨论

随时划词评论，并在原文旁继续讨论，评论与正文位置一一对应。每条评论都是一个讨论线程，支持多轮回复、@ 提及和状态流转。

![划词评论后在原文旁展开讨论线程](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/md-comment-discussion.DGPDgb76.png)

### 生成和审阅修订建议

划词选中需要修改的内容并提出要求后，AI 会生成修订建议，而不是直接覆盖原文。每条建议都会显示在原文旁，方便你检查修改内容：

- **保留原文**：原文保持不变，修改建议标记为「待确认」状态。
- **对比查看**：会话中会列出「原文 / 改后」对照表，说明本轮改了什么、为什么这么改
- **审阅处理**：可以逐条接受或拒绝，也可以一次性接受全部建议。只有接受的修改才会写入正文。

这种方式适合对外提案、协作写作稿等需要谨慎控制内容变更的文档。对于重要内容，建议逐条核对原文与修改结果，确认无误后再接受，避免未经确认的改动进入正文。

关于划词选区编辑的操作细节，以及在 Word / Excel / PPT 等办公文件中与 AI 协作编辑，参见[人机双写](./../Knowledge-Base/Cowriting)。

### 按评论修订

收到多条评论后，使用「按评论修订」，AI 会结合评论内容及正文上下文，生成对应的修订建议，帮助你集中处理各项修改意见，无需逐条对照评论手动修改。审阅并接受建议后，还可以通知评论者复核修改结果。

### 撤销与重做

与 AI 协作编辑本地文档（如 PPT）时，每次 AI 修改都会与手动操作一样记录在撤销栈中。发现修改不符合预期时，可以按操作顺序逐层撤销 AI 或手动修改；需要恢复时，也可以通过重做还原已撤销的内容。

- **撤销**：逐层撤销 AI 修改或手动修改，按操作顺序回退。
- **重做**：恢复刚刚撤销的内容。

本地文档中与 AI 协作编辑的完整能力，参见[人机双写](./../Knowledge-Base/Cowriting)。

## 在 HTML 页面中修改和协同编辑

划词修改与多人编辑都在同一份 HTML 里发生，改动即时可见。

### 划词让 AI 修改

在 HTML 中划词调用 AI，直接修改当前选中的内容。

![在 HTML 页面中划词调用 AI 修改选中内容](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/html-ai-selection.B58ksPx4.png)

### 多人一起编辑 HTML

HTML 可直接编辑，多位协作者的光标和修改状态同时可见。

## MD 与 HTML 的修改方式对比

两种载体的 AI 协作方式不同，按载体使用对应方式：

| 载体 | AI 修改方式 | 生效时机 |
| --- | --- | --- |
| MD 文档 | 划词提出修改要求，生成修订建议 | 审阅并点击「接受」后才写入正文 |
| HTML 页面 | 划词调用 AI，直接修改选中内容 | 改动即时可见，无需审阅确认 |

## 集中查看和管理评论

当页面评论较多，需要集中跟进讨论或避免评论气泡影响正文阅读时，可以通过评论面板筛选和管理评论，也可以根据需要隐藏正文中的评论气泡。

### 筛选和查看评论

页面右上角有一个评论图标，图标旁的数字是当前**未解决**的评论数：

![页面右上角的评论入口，数字为未解决评论数](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/comment-entry.QtEJ1j_b.png)

点击后展开评论面板：

![评论面板：按未解决筛选，逐条查看与操作](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/comment-panel.Dpk9SIkG.png)

- 面板顶部显示「评论」，并可按 **未解决** 筛选；
- 每条评论显示评论者、时间和评论内容；右侧的 **⋯** 提供针对这条评论的操作；
- 点右上角的关闭按钮收起面板。

MD 文档和 HTML 页面都从这里查看评论。

### 隐藏页面上的评论气泡

评论较多、影响阅读正文时，可以暂时把页面上的评论气泡隐藏：点击评论面板右上角的 **眼睛图标**（悬停提示「隐藏评论」），当前页面上的评论气泡就会隐藏；再点一次即可恢复显示。隐藏后，评论面板里的评论列表仍然可以正常查看。

![评论面板右上角的眼睛图标，点击即可隐藏页面上的评论气泡](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/comment-hide-eye.BzbqNKlf.png)

## 用 MD、CSV 和 HTML 分工管理内容

MD 决定内容，CSV 存储数据，HTML 负责表达；数据与视觉分离，按场景灵活调整。这也是资料库区别于普通网盘的核心——三种载体互相引用、彼此联动，而不是把文件堆在一起。需要多人协同调整页面布局时，使用 HTML；需要多人维护记录、清单或排期时，使用 CSV。

| 形态 | 职责 | 修改时机 |
| --- | --- | --- |
| **MD** | 决定内容，承载文字与结构 | 需要调整叙述、结构和结论时改 MD |
| **CSV** | 存储数据，作为唯一数据源 | 需要更新数值、新增记录时改 CSV |
| **HTML** | 提供视觉表达，读取 CSV 渲染 | 需要调整版式、配色和交互时改 HTML |

先在 MD 中把内容和结构写清楚：

![在 MD 编辑器中撰写内容](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/editor-md.Clks4dR2.png)

再由 MD 生成 HTML 页面用于对外呈现，同一份内容获得面向读者的版式：

![由 MD 生成的 HTML 页面](https://download.codebuddy.cn/web/docs/af0e54f92708bef8d26b3d66b4310b3fe33a1bd1/docs/static/editor-md-to-html.BdKdBjE4.png)

CSV 由 WorkBuddy 在线表格承载，多人可以同时维护；HTML 页面通过表格 ID 读取数据并实时渲染，因此 CSV 更新后页面随之刷新，无需重新导出。内容、数据和呈现各自独立，改一处不影响其他部分。
